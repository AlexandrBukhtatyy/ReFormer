Перегенерируй инфографику по коду `@reformer/*` и отчитайся о результате.

1. Запусти из корня репозитория:

   ```bash
   npm run diagram -- $ARGUMENTS
   ```

   Полный прогон занимает несколько минут (два прохода компилятора TypeScript по всему
   монорепозиторию) — ставь timeout не меньше 600000 мс. Если аргументов нет, путь вывода
   берётся из `REFORMER_DIAGRAM_OUT`, иначе `.tmp/code-viz/Reformer-all.excalidraw.md`.

2. Разбери вывод и коротко сообщи:
   - куда записан файл, сколько элементов;
   - сводку по пакетам (боксы / файлы / символы) и число рёбер вызовов;
   - результат проверки читаемости линий. Пункты 1–3 (дубли точек прикрепления, наложения
     параллельных линий, пересечения с блоками) должны быть нулевыми — если нет, это
     регрессия геометрии, скажи об этом явно.

3. Не коммить результат и не правь схему без отдельной просьбы.

Устройство пайплайна и правила правок — [scripts/diagrams/README.md](../../scripts/diagrams/README.md).
