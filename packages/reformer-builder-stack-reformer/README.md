# @reformer/builder-stack-reformer

Стек ReFormer для ReFormer Builder: предметный код, общий для плагинов, которые редактируют,
показывают, проверяют и печатают формы `@reformer/renderer-json`.

```bash
npm install @reformer/builder-stack-reformer
```

## Зачем пакет, а не каталог билдера

Плагины билдера не импортируют друг друга — связь между ними идёт через службы, команды
и события. Но чистые функции без состояния (модель схемы, каталог, печать модуля формы) нужны
сразу нескольким плагинам стека: редактору схемы, превью, ассистенту, кодогену, шаблонам,
валидатору. Раньше они жили в `src/lib` билдера — там их видели встроенные плагины, но не видел
никто снаружи, а сам каталог назывался «общий», хотя целиком говорил на языке одного формата.

Пакет делает стек единицей: всё, что знает про схему ReFormer, лежит здесь, а оболочка билдера
и нейтральные плагины от этого пакета не зависят (проверяется линтером билдера).

## Модули

Импорт — по модулю, а не по файлу:

```ts
import { insertNode, walkNodes } from '@reformer/builder-stack-reformer/form-model';
import { buildCatalog, type CatalogEntry } from '@reformer/builder-stack-reformer/catalog';
```

| Вход             | Что внутри                                                                                   |
| ---------------- | -------------------------------------------------------------------------------------------- |
| `./form-model`   | адресация (JSON Pointer, `$nodeId`), вложенность DSL, иммутабельные правки, запросы, правила |
| `./catalog`      | контракт каталога компонентов, палитра, инспектор, фабрики узлов                             |
| `./kits`         | дескриптор UI-кита и дефолты «неявного кита» `@reformer/ui-kit`                              |
| `./codegen`      | печать модуля формы: контекст, вид для шаблонов, встроенные шаблоны `.eta`                   |
| `./form-mock`    | синтез начальных значений и источников данных по схеме                                       |
| `./form-fixture` | формат `fixture.ts` формы, слияние слоёв данных, песочница `fetch`/`Date`/`Math`             |
| `./form-inspect` | чтение и правка живой модели формы по `$model`-пути                                          |
| `./testing`      | фикстуры для тестов потребителей (схема-образец, встроенный каталог, киты)                   |

## Состояние здесь не живёт

«Какой кит активен», «какой документ открыт», «что выделено» — состояние, и оно принадлежит
плагинам и службам билдера. Здесь только то, что из данных следует.

## Другие стеки

Стек — не единственный: демо-стек `@reformer/builder-stack-plain` приносит свой формат схемы,
нативную отрисовку и свой экспорт и не зависит от этого пакета. Что нужно ЛЮБОМУ стеку, лежит
в `@reformer/builder-toolkit`.
