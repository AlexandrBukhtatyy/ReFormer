# Чек-лист ревью формы

Короткий список для проверки формы на `@reformer` за пять минут. Собран по итогам реального
переноса большой формы между UI-китами (см. рекомендации §10). Проверяет границы слоёв и типовые
молчаливые поломки.

## Границы слоёв

- [ ] в `form.json` только структура и пропы — **никаких функций и рантайм-сущностей** (правила,
      расчёты, компоненты живут в TS-файлах, не в схеме);
- [ ] правила валидации (`form.validation.*`) **не импортируют** React и папку моста к UI-kit
      (валидация — над сигналами модели, а не над деревом рендера);
- [ ] `form.behavior` меняет только поля модели, `ui.behavior` — только дерево рендера
      (видимость/patchProps/события); бизнес-расчёты не в `ui.behavior`.

## Связи по строкам (ломаются молча)

- [ ] у каждого узла, который адресует поведение, есть `selector`, и он в union-типе селекторов
      страницы (опечатка → ошибка компиляции, а не тихий промах);
- [ ] `$model(path)` пути соответствуют форме модели — типизируй схему `defineJsonSchema<T>()`,
      чтобы опечатка ловилась компилятором;
- [ ] `initialValue` массива содержит **все** ключи элемента (иначе у элемента нет части сигналов и
      поля не рендерятся) — `validateSchema` это теперь проверяет;
- [ ] `validateSchema` включён хотя бы в dev (`validateSchema={import.meta.env.DEV}`) — ловит
      неизвестные `$component`/`$dataSource` и структурные ошибки до рендера.

## Валидация и видимость

- [ ] пошаговая валидация помечает поля `touched` — иначе блокировка перехода невидима; используй
      `validateModel(model, schema, { touch: true })`, а не ручной `form.markAsTouched()` на всё
      поддерево;
- [ ] скрытие секции (`hideWhen`) идёт в паре с отключением/сбросом полей в `form.behavior` — иначе
      скрытое поле продолжает валидироваться и уезжает в payload;
- [ ] предикаты `hideWhen` читают сигнал целиком (`form.x.value.value`), иначе они не реактивны.

## Рендер и мост

- [ ] `renderBehavior` стабилен по ссылке (иначе дерево пересобирается каждый рендер — в dev теперь
      есть предупреждение);
- [ ] у каждого контрола в реестре, который сам потребляет ноду формы, стоит `reformerNeedsControl`
      либо `passControl` в его `FieldAdapter`; остальным `control` не нужен;
- [ ] модель и форма собираются **один раз** — через `createJsonForm` + `useJsonForm` (ленивый
      `useState`), а не пересоздаются в `useMemo`/на каждый рендер (иначе теряется введённое);
- [ ] реестр уровня страницы — это нормально и должно быть дефолтом; в общий реестр моста выносится
      только то, что переиспользуется несколькими формами.
