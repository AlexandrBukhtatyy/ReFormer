# @reformer/mcp

MCP-сервер ReFormer для агента — Claude Code, Cursor и других клиентов MCP. Помогает агенту собирать
формы на [ReFormer](https://github.com/AlexandrBukhtatyy/ReFormer): описывает форму, собирает модуль,
проверяет код и отвечает на вопросы по API.

Пакет — тонкий клиент сервиса ReFormer. Инструменты, справка и сборка формы работают в сервисе, а на
вашей машине остаётся то, что касается ваших файлов:

- чтение и запись каталога формы;
- проверка типов компилятором вашего проекта;
- чтение спецификации формы;
- отчёты `report_issue` в `.reformer/`.

## Подключение

Нужен ключ сервиса ReFormer. Добавьте сервер в `.mcp.json` проекта:

```json
{
  "mcpServers": {
    "reformer": {
      "command": "npx",
      "args": ["-y", "@reformer/mcp"],
      "env": { "REFORMER_API_KEY": "<ваш ключ>" }
    }
  }
}
```

## Окружение

| Переменная             | Что задаёт                                                                                     |
| ---------------------- | ---------------------------------------------------------------------------------------------- |
| `REFORMER_API_KEY`     | Ключ сервиса. Без него облачный сервис не отвечает, и клиент сразу об этом скажет              |
| `REFORMER_SERVICE_URL` | Адрес сервиса без пути — для сервиса, развёрнутого у себя. По умолчанию облачный               |
| `REFORMER_SURFACE`     | Набор инструментов: `code-guided-dsl` (по умолчанию), `tools`, `code`, `guided`, `code-guided` |
| `REFORMER_TRACE_FILE`  | Журнал вызовов в файл (JSON Lines)                                                             |

## Что уходит в сервис

С каждым вызовом клиент передаёт сервису то, что нужно этому вызову: файлы каталога формы,
спецификацию, результат проверки типов и каталог компонентов `@reformer/ui-kit`, если он установлен.
Записи сервис возвращает операциями — пишет их на диск клиент.
