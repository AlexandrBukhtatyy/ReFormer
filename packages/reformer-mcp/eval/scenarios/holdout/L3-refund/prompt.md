Заявка на возврат денег. Причина (reason): defect — брак, other — другое; по умолчанию выбран defect. Комментарий (comment) виден и обязателен только при other. Сумма покупки (amount) обязательна и не меньше 1. Удержание в процентах (feePercent) от 0 до 30, по умолчанию 0. К возврату (refund) = amount × (1 − feePercent / 100): поле только для чтения, считается само.
