В каталоге `form/` уже готов мастер оформления заказа, его спецификация — в `spec.md` (раздел
спецификации — шаг мастера). Доработай мастер:

1. Шаг «Оплата» переименуй в «Оплата и скидки».
2. Комментарий к заказу (`comment`) перенеси с шага «Оплата» на шаг «Подтверждение» — перед
   согласием с офертой. Правило поля остаётся прежним.
3. Между шагами «Товары» и «Оплата» добавь шаг «Упаковка»:
   - «Подарочная упаковка» (`giftWrap`) — Switch, по умолчанию выключен;
   - «Текст открытки» (`giftMessage`) — Textarea, не больше 200 символов («Не больше 200 символов»);
     виден и обязателен («Напишите текст открытки») только при подарочной упаковке.

Остальное в мастере не меняй.
