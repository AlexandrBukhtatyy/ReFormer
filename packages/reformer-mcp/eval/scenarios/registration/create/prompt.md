Сделай форму регистрации:

- логин (`login`) — обязателен, от 3 до 20 символов, только латиница, цифры и `_`;
- email (`email`) — обязателен, проверяется формат;
- пароль (`password`) — обязателен, минимум 8 символов, ввод скрыт;
- повтор пароля (`confirmPassword`) — обязателен и должен совпадать с паролем;
- капча (`captcha`) — поле для кода из 6 символов с картинки, обязательна. Сервера капчи пока нет:
  проверяй асинхронно заглушкой — верный код `ABC123` без учёта регистра, ответ через 300 мс,
  неверный код — ошибка «Символы не совпадают». Картинку пока не рисуй;
- внизу кнопка «Зарегистрироваться».
