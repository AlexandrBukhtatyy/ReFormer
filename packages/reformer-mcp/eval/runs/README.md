# Опубликованные прогоны `@reformer/mcp`

Записи всех стендов качества в одном формате: `reformer-mcp-run/1`
([схема](../records/schema.json)). Один файл `.jsonl` — один батч,
одна строка — один прогон.

Файл появляется здесь только по `--publish`. Без флага запись остаётся в
`.tmp/mcp-runs/<батч>/records.jsonl` вместе с сырьём: транскриптами, журналами вызовов и файлами форм.
Отладочные прогоны в истории не нужны, а сырьё в репозиторий не кладётся.

| Стенд                  | Как опубликовать                                                  |
| ---------------------- | ----------------------------------------------------------------- |
| извлечение знания      | `npm run mcp:evaluate -- --publish`                               |
| калибровка             | `npm run mcp:calibrate -- --publish`                              |
| сценарии               | `npm run mcp:scenarios -- --matrix <имя> --publish`               |
| ассистент конструктора | `npm run mcp:import-builder -- <form-scenarios-*.json> --publish` |

## Как читать

```bash
npm run mcp:compare -- <A> <B>            # файл, идентификатор батча или baseline:<ключ>
npm run mcp:compare -- <A> <B> --gate     # код 1 при регрессии
npm run mcp:report                        # .tmp/mcp-eval/report/index.html: тренды и матрица
```

`baselines.json` даёт эталонным батчам имена: `{ "scenarios-qwen": "20261102T164814Z-188b" }`.

## Что важно помнить

- **Один прогон с моделью ничего не доказывает.** При трёх повторах значим только переход 0/3 ↔ 3/3
  (точный тест Фишера, p=0.1). Для решений нужно N=5 и больше.
- **`invalid` — сломался прибор, а не форма:** нарушена изоляция, агент не запустился, исчерпан бюджет.
  В статистику такие прогоны не входят.
- **`costUsd` у Claude Code — оценка:** запуск идёт по подписке (`agent.auth: "oauth"`), это не списание.
- **Токены у стендов без модели — оценка `chars / 4`**, у агентов — данные провайдера. Между собой не
  сравниваются.
- **`source.provenance: "imported"`** — коммит в записи текущий на момент импорта, а не коммит прогона.
- **Holdout** в сравнении и в сводке виден только агрегатом. Провалы holdout не становятся задачами на
  правку сервера.
