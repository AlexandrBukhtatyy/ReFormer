Снимок бэклога после сверки всех открытых задач с кодом и историей. Задачи сгруппированы по областям и
расставлены по приоритету: у каждой — суть проблемы и предлагаемое решение (после «→»). Приоритеты
перенесены в beads; актуальное состояние смотрите там, этот файл со временем устареет.

## Обозначения и как это лежит в beads

| Метка | Смысл                                                         | В beads                         |
| ----- | ------------------------------------------------------------- | ------------------------------- |
| П1    | делать первым: блокирует остальное или бьёт по людям сейчас   | P1                              |
| П2    | следующим                                                     | P2                              |
| П3    | когда будет время                                             | P3                              |
| П4    | по мере надобности: заводить работу, когда появится потребитель | P4                            |
| Р     | ждёт решения владельца или ручного/внешнего действия          | P2–P4 + метка `needs-decision`  |
