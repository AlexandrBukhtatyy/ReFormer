# @reformer/builder-v2

Визуальный конструктор форм ReFormer, вторая версия. Пакет несёт уже собранный офлайн-SPA
в `dist/` и zero-dependency лаунчер: `npx reformer-builder2` поднимает локальный сервер
и открывает браузер. Серверной логики нет — файлы проекта билдер читает и пишет прямо
из браузера через File System Access API (нужен Chromium: Chrome/Edge/Arc/Brave).

## Запуск

```bash
npx reformer-builder2 [--port 4322] [--host 127.0.0.1] [--no-open] [--config <path>]
```

## Конфигурация — каталог `.ui_builder/`

Один конвенционный каталог на два момента чтения:

| Что                                                                                                                                                | Где                                         | Когда читается                                                                                                   |
| -------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| `config.json` — брендинг, дефолты UI                                                                                                               | каталог запуска (`--config` переопределяет) | лаунчером при старте                                                                                             |
| `config.json`                                                                                                                                      | открытый проект                             | при каждом открытии проекта; перекрывает уровень запуска по полю (`defaults` действуют только на уровне запуска) |
| `plugins/<id>/` — плагины: `manifest.json`, `main.js` (собранный) или `main.ts` (в разработке — транспиляция на лету, авто-перезагрузка по правке) | открытый проект                             | при открытии; включение — явное действие человека                                                                |
| `templates/<slug>/` — шаблоны форм                                                                                                                 | открытый проект                             | службой шаблонов                                                                                                 |
| `codegen/*.eta` — свои цели генерации                                                                                                              | открытый проект                             | плагином кодогенерации                                                                                           |

Запустили `npx reformer-builder2` в корне проекта и его же открыли — вся конфигурация
в одном `.ui_builder/`, без дублей.

`config.json` (все секции опциональны; `$schema` даёт автодополнение в IDE):

```json
{
  "$schema": "./node_modules/@reformer/builder-v2/runtime-config.schema.json",
  "branding": { "title": "Формы Acme" },
  "defaults": { "locale": "ru", "theme": "system" }
}
```

Сторонний ui-kit встраивается плагином (плагин привозит и каталог компонентов, и код),
а не файлом данных — механизм в работе.
