# Вёрстка: контейнеры, HTML и текст

Кроме полей, схема описывает вёрстку: секции, колонки, заголовки, поясняющий текст и живую сводку
значений. Для этого есть узел-контейнер. Его `component` — компонент Vue или HTML-тег строкой, а
`children` — вложенные узлы и текст вперемешку. Само дерево то же, что у React: отличается только
то, как рендерер передаёт пропсы и детей во Vue.

## Когда это нужно

- Поля нужно разложить по секциям и колонкам.
- В форме есть заголовки, плашки с пояснением, разделители — заводить под них компоненты не хочется.
- Нужна сводка, которая пересчитывается на лету: «Платёж в месяц: 12 500 ₽».

## Пример

```ts
import type { FormModel, FormSchemaNode } from '@reformer/core';
import { computed } from '@reformer/core/signals';
import { InputNumber, Section } from '@reformer/kit-vuetify';

type Installment = { amount: number; months: number };

export const installmentSchema = (model: FormModel<Installment>): FormSchemaNode => {
  // Вычисляемый текст — обычный computed над моделью.
  const monthly = computed(() => Math.round((model.amount ?? 0) / (model.months || 1)));

  return {
    component: 'div',
    componentProps: { className: 'space-y-6' },
    children: [
      {
        component: 'h2',
        componentProps: { className: 'text-xl font-bold' },
        children: ['Рассрочка'],
      },
      {
        component: Section,
        componentProps: { title: 'Условия' },
        children: [
          { model: model.$.amount, component: InputNumber, componentProps: { label: 'Сумма, ₽' } },
          {
            model: model.$.months,
            component: InputNumber,
            componentProps: { label: 'Срок, мес.' },
          },
        ],
      },
      { component: 'hr' },
      // Текст и сигналы в children: перерисовывается только сам текст.
      { component: 'p', children: ['Платёж в месяц: ', monthly, ' ₽'] },
    ],
  };
};
```

Тип узла — `FormSchemaNode` из `@reformer/core`. `RenderNode` в этом пакете — компонент, а не тип
узла.

## Контейнер

| Ключ             | Что задаёт                                                             |
| ---------------- | ---------------------------------------------------------------------- |
| `component`      | компонент Vue (`Section`, `Box`) или тег строкой (`'div'`, `'p'`)      |
| `componentProps` | пропсы компонента; у тега — атрибуты DOM (`className`, `id`, `aria-*`) |
| `children`       | вложенные узлы и текстовые части                                       |
| `selector`       | имя узла для поведения и шагов потока                                  |

- `children` — ключ самого узла. Внутри `componentProps` вложенные узлы не рисуются.
- Контейнер без `component` (или с пустой строкой) рисует только своих детей — удобно, чтобы
  сгруппировать узлы без лишней разметки.
- Компонент-контейнер получает детей **слотом `default`**: `slots.default?.()` в рендер-функции или
  `<slot />` в шаблоне. У контейнера без детей слота нет.
- Сигнал в `componentProps` контейнера (`{ title: model.$.kind }`) приходит компоненту значением и
  следует за моделью.

Пропсы, которых компонент не объявил, Vue отдаёт атрибутами его корню. Поэтому рендерер передаёт
два служебных ключа с оглядкой на объявление:

- `selector` получает только компонент, который объявил проп `selector`. Остальным он не уходит и в
  DOM не попадает.
- `className` из `componentProps` уходит компоненту как есть, только если тот объявил проп
  `className`. Иначе рендерер переименовывает его в `class`, и Vue кладёт класс на корень.

## HTML-теги

Тег строкой рисуется как есть: `{ component: 'h3', children: ['Итого'] }` даёт `<h3>Итого</h3>`.
Отдельный компонент нужен, только когда у блока есть своя логика или состояние.

- Пропсы схемы написаны в диалекте React, а Vue ждёт имена атрибутов DOM: рендерер переводит
  `className` → `class` и `htmlFor` → `for`. Остальное Vue понимает как есть: `style` объектом,
  `data-*`, `aria-*`, обработчики `onClick`.
- `selector` в DOM не попадает: он адресует узел схемы, а не элемент. `hideWhen` по нему работает.
- Пустые теги (`hr`, `br`, `img`, `input` и другие) детей не получают — их `children` пропускаются.
  Тег без детей рисуется без содержимого.
- Теги и компоненты вкладываются друг в друга в любом порядке.

## Текст

Ребёнок контейнера — узел либо текстовая часть:

| Текстовая часть | Пример                              | Обновляется                     |
| --------------- | ----------------------------------- | ------------------------------- |
| строка, число   | `'Итого: '`, `42`                   | нет                             |
| сигнал поля     | `model.$.monthlyPayment`            | при изменении значения          |
| `computed(…)`   | `computed(() => model.a + model.b)` | при изменении прочитанных полей |

- Соседние части склеиваются без разделителя. Пробелы ставьте в строках сами.
- Порядок в `children` сохраняется: `['Важно: ', { component: 'b', children: ['срок'] }, ' истёк']`.
- `null` и `undefined` в сигнале дают пустую строку.
- Подряд идущие части рисуются одним текстом, подписанным на свои сигналы точечно: смена значения
  перерисовывает только этот текст, а не поддерево узла.
- Текст у компонента-контейнера приходит ему в слот `default`:
  `{ component: Button, children: ['Отправить'] }`.

## Узлы по условию

Условие, которое известно при сборке, решается обычным кодом: `...(withPhone ? [phoneNode] : [])`.
Пустые места (`null`, `undefined`, `false`) в `children` компилятор схемы пропускает.

Условие, которое меняется во время работы формы, — правило `hideWhen` в поведении формы. См.
[Управление узлами](./node-control.md).

## Подводные камни

- **Текст не обновляется** — значение подставлено строкой при построении схемы:
  `` `Платёж: ${model.monthlyPayment}` `` читает его один раз. Передавайте сам сигнал:
  `['Платёж: ', model.$.monthlyPayment]`.
- **Контейнер пустой** — `children` положили в `componentProps`, или компонент не рисует слот
  `default`.
- **На корне компонента лишние атрибуты** — компонент не объявил пропсы из `componentProps`. Vue
  отдаёт их атрибутами корню: необъявленный `title` станет всплывающей подсказкой. Объявляйте всё,
  что компонент получает из схемы.
- **Компоненты, которые ведут детей сами** (визард, вкладки), получают детей узлами, а не текстом:
  текстовые части им не передаются, в dev — предупреждение. См.
  [Управление узлами](./node-control.md#компонент-сам-рисует-детей).
