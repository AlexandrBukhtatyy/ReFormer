# FieldArray

Headless compound-компонент для динамических массивов из `@reformer/cdk`. Массив
принадлежит модели (`model.<field>`), в схеме объявляется узлом
`{ model: model.$.items, item: (row) => узел }`, а `FieldArray.*` получает ноду массива
(`control={form.items}`, `FormArray<T>`) и раздаёт состояние и обработчики через render-props —
разметку и стили вы пишете сами. Ключ строки (`id` в render-props) — `keyAt(index)` ноды: он
держится за элемент и не меняется при перестановке. Для готового вида используйте
`FieldArraySection` из [`@reformer/ui-kit`](../ui-kit/field-array).
