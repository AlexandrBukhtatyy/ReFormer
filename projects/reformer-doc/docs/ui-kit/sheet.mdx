# Sheet

Панель, которая выезжает от края экрана поверх страницы. Внутри — заголовок, содержимое и кнопки.
Ведёт себя как модальное окно: страница под панелью недоступна. Построена на Radix Dialog и
входит в [кит](../reference/glossary.md#пакеты) `@reformer/ui-kit`, это не поле формы.

## Когда брать

- **Sheet** — много содержимого, связанного с текущей страницей: фильтры списка, настройки,
  редактирование записи, меню разделов на узком экране.
- [Dialog](./dialog.mdx) — короткая задача в центре экрана.
- [Drawer](./drawer.mdx) — шторка для телефона, которую смахивают пальцем. Sheet жестов не
  понимает.
- [AlertDialog](./alert-dialog.mdx) — подтверждение необратимого действия.
- [Sidebar](./sidebar.mdx) — постоянная боковая навигация приложения, а не временная панель.

## Анатомия

```tsx
import {
  Sheet,
  SheetTrigger,
  SheetContent,
  SheetHeader,
  SheetTitle,
  SheetDescription,
  SheetFooter,
  SheetClose,
} from '@reformer/ui-kit'; // или '@reformer/ui-kit/sheet'

<Sheet>
  <SheetTrigger asChild>
    <Button variant="outline">Фильтры</Button>
  </SheetTrigger>
  <SheetContent side="right">
    <SheetHeader>
      <SheetTitle>Фильтры</SheetTitle>
      <SheetDescription>Сузьте список заявок.</SheetDescription>
    </SheetHeader>
    <div className="px-4">{/* поля фильтров */}</div>
    <SheetFooter>
      <SheetClose asChild>
        <Button>Показать</Button>
      </SheetClose>
    </SheetFooter>
  </SheetContent>
</Sheet>;
```

| Часть              | Что это                                                      | Ключевые пропсы                                 |
| ------------------ | ------------------------------------------------------------ | ----------------------------------------------- |
| `Sheet`            | Корень: хранит, открыта ли панель.                           | `open` + `onOpenChange`, `defaultOpen`, `modal` |
| `SheetTrigger`     | Кнопка, которая открывает панель.                            | `asChild`                                       |
| `SheetContent`     | Сама панель в портале, с затемнением фона и крестиком.       | `side` (`right`), `showCloseButton` (`true`)    |
| `SheetHeader`      | Шапка с отступами.                                           | —                                               |
| `SheetTitle`       | Заголовок панели. Обязателен.                                | —                                               |
| `SheetDescription` | Пояснение под заголовком.                                    | —                                               |
| `SheetFooter`      | Кнопки, прижатые к низу панели, столбиком.                   | —                                               |
| `SheetClose`       | Закрывает панель. Обычно оборачивает свою кнопку или ссылку. | `asChild`                                       |

- `side` — край: `right` (по умолчанию), `left`, `top`, `bottom`. Боковая панель занимает 3/4
  ширины, на широком экране — не больше `max-w-sm`; верхняя и нижняя — по высоте содержимого.
- Отступы есть только у шапки и подвала (16px). Содержимому между ними задайте свой отступ —
  `px-4`.
- Панель закрывают крестик, `Esc`, щелчок по затемнению и любой `SheetClose`. Чтобы закрыть её из
  кода, управляйте открытием сами: `open` и `onOpenChange`.

## Доступность

Sheet — это Radix Dialog, поэтому поведение то же, что у [Dialog](./dialog.mdx#доступность):

| Клавиша             | Действие                                                    |
| ------------------- | ----------------------------------------------------------- |
| `Enter` / `Space`   | На триггере — открыть панель.                               |
| `Tab` / `Shift+Tab` | Перейти по элементам панели; фокус не уходит за её пределы. |
| `Esc`               | Закрыть панель.                                             |

- При открытии фокус переходит в панель, при закрытии возвращается на триггер.
- У панели `role="dialog"`; заголовок и описание связаны с ней через `aria-labelledby` и
  `aria-describedby`. `SheetTitle` обязателен — скрыть его можно классом `sr-only`.
- Остальная страница скрыта от скринридера, прокрутка под панелью заблокирована.
- Крестик — кнопка с иконкой; её имя («Закрыть») — скрытая подпись из словаря кита.

## Локализация

Кит рисует сам одну строку — скрытую подпись крестика:

| Ключ словаря      | English | Русский |
| ----------------- | ------- | ------- |
| `kit.sheet.close` | Close   | Закрыть |

Язык берётся из `I18nProvider` (`@reformer/core/react`) с локалью кита `loadKitLocale` из
`@reformer/ui-kit/locale`; без провайдера подпись английская. Пропа для неё нет: для одной панели
уберите крестик (`showCloseButton={false}`) и поставьте свою `SheetClose`, для всего приложения —
добавьте источник словаря после `loadKitLocale`:

```tsx
import { createLocaleLoader } from '@reformer/core/i18n';
import { loadKitLocale } from '@reformer/ui-kit/locale';

const loadLocale = createLocaleLoader([
  loadKitLocale,
  (code) => (code === 'ru' ? { 'kit.sheet.close': 'Закрыть панель' } : null),
]);
```
