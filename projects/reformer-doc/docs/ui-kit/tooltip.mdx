# Tooltip

<ComponentDoc config={tooltipDocConfig}>
Короткий текст, который появляется, когда курсор наведён на элемент или элемент получил фокус с
клавиатуры. Обычно поясняет кнопку-иконку. Построен на Radix Tooltip и входит в
[кит](../reference/glossary.md#пакеты) `@reformer/ui-kit`, это не поле формы.

## Когда брать

- **Tooltip** — одна строка к кнопке-иконке или сокращению: «Удалить», «Скопировать ссылку».
- [InfoHint](./info-hint.mdx) — пояснение к полю или заголовку за иконкой (i). Открывается ещё и
  касанием на телефоне.
- У полей формы подсказку дают пропсы `labelTooltip` и `tooltip` — их рисует
  [FormField](./form-field.mdx), Tooltip вручную не нужен.
- [HoverCard](./hover-card.mdx) — превью с несколькими строками и картинкой.
- [Popover](./popover.mdx) — панель с кнопками или полями, по щелчку.

На телефоне наведения нет, а касание Tooltip не открывает. Текст, без которого не обойтись, пишите
на странице или берите InfoHint.

## Анатомия

```tsx
import { TooltipProvider, Tooltip, TooltipTrigger, TooltipContent } from '@reformer/ui-kit'; // или '@reformer/ui-kit/tooltip'

// Необязательно — один раз у корня приложения, чтобы задать общие настройки:
<TooltipProvider>
  <App />
</TooltipProvider>;

// Где нужна подсказка:
<Tooltip>
  <TooltipTrigger asChild>
    <Button size="icon" variant="ghost" aria-label="Удалить">
      <Trash2 />
    </Button>
  </TooltipTrigger>
  <TooltipContent>Удалить</TooltipContent>
</Tooltip>;
```

| Часть             | Что это                                                           | Ключевые пропсы                                         |
| ----------------- | ----------------------------------------------------------------- | ------------------------------------------------------- |
| `TooltipProvider` | Общие настройки подсказок. Необязателен.                          | `delayDuration` (`0`), `skipDelayDuration`              |
| `Tooltip`         | Одна подсказка.                                                   | `open` + `onOpenChange`, `defaultOpen`, `delayDuration` |
| `TooltipTrigger`  | Элемент, к которому относится подсказка. По умолчанию `<button>`. | `asChild`                                               |
| `TooltipContent`  | Текст подсказки в портале, со стрелкой.                           | `side` (`top`), `align`, `sideOffset` (`0`)             |

- Без `TooltipProvider` выше по дереву `Tooltip` ставит провайдер кита сам. Общий провайдер у
  корня приложения нужен, чтобы задать настройки один раз и чтобы соседние подсказки показывались
  без повторной задержки.
- Задержка показа по умолчанию — 0 мс: и у `TooltipProvider` кита, и у провайдера, который
  `Tooltip` ставит сам. Чтобы подсказки не всплывали при каждом проезде курсора, задайте
  `delayDuration` (например, 300).
- Если не хватает места, подсказка сама переезжает на другую сторону.

## Доступность

Клавиатуру и атрибуты даёт Radix Tooltip:

| Клавиша           | Действие                                                     |
| ----------------- | ------------------------------------------------------------ |
| `Tab`             | Фокус на триггер показывает подсказку, уход фокуса — прячет. |
| `Esc`             | Спрятать подсказку.                                          |
| `Enter` / `Space` | Нажать триггер; подсказка при этом прячется.                 |

- Пока подсказка видна, триггер ссылается на неё через `aria-describedby`, у текста —
  `role="tooltip"`. Скринридер прочитает подсказку как описание элемента.
- Подсказка — описание, а не имя. Кнопке-иконке всё равно нужен свой `aria-label`.
- В подсказке не должно быть ссылок и кнопок: до них нельзя дойти клавиатурой.
- Касанием на сенсорном экране подсказка не открывается.

## Локализация

Своих строк компонент не рисует: текст подсказки — ваш.
