Круглое фото пользователя. Пока картинка грузится или если ссылка битая, на её месте видны
инициалы. Построен на Radix Avatar и входит в [кит](../reference/glossary.md#пакеты)
`@reformer/ui-kit`, это не поле формы.

## Когда брать

- **Avatar** — человек или организация рядом с именем: автор комментария, исполнитель задачи,
  пользователь в шапке.
- **AvatarGroup** — несколько участников в одну строку, лишние сворачиваются в «+N».
- [Icon](./icon.mdx) — значок без фото и инициалов.
- [Badge](./badge.mdx) — текстовая метка рядом с именем («админ», «гость»).
- [HoverCard](./hover-card.mdx) — подробная карточка человека по наведению на аватар или имя.

## Анатомия

```tsx
import {
  Avatar,
  AvatarImage,
  AvatarFallback,
  AvatarBadge,
  AvatarGroup,
  AvatarGroupCount,
} from '@reformer/ui-kit'; // или '@reformer/ui-kit/avatar'

<Avatar size="lg">
  <AvatarImage src="/users/42.png" alt="Иван Петров" />
  <AvatarFallback>ИП</AvatarFallback>
</Avatar>;
```

| Часть              | Что это                                           | Ключевые пропсы               |
| ------------------ | ------------------------------------------------- | ----------------------------- |
| `Avatar`           | Корень — круг заданного размера.                  | `size`: `sm`, `default`, `lg` |
| `AvatarImage`      | Картинка. Показывается, только когда загрузилась. | `src`, `alt`                  |
| `AvatarFallback`   | Запасное содержимое — обычно инициалы.            | `delayMs`                     |
| `AvatarBadge`      | Точка или значок статуса в правом нижнем углу.    | `className` — цвет            |
| `AvatarGroup`      | Ряд аватаров внахлёст.                            | —                             |
| `AvatarGroupCount` | Кружок «+N» в конце группы.                       | —                             |

Размеры: `sm` — 24px, `default` — 32px, `lg` — 40px. Шрифт инициалов, точка статуса и кружок «+N»
подстраиваются под размер сами. Инициалы вы передаёте готовыми — компонент их не вычисляет.

## Доступность

- Загруженную картинку скринридер читает по `alt`. Если имя написано рядом с аватаром, поставьте
  `alt=""`, чтобы имя не звучало дважды.
- Пока картинки нет, скринридер читает инициалы буквами — «И П». Если аватар — единственное, что
  называет человека, дайте корню `role="img"` и `aria-label` с полным именем: содержимое такого
  элемента скринридер не читает.
- Точка статуса (`AvatarBadge`) видна только глазами. Статус скажите словами — в `aria-label`
  аватара или текстом рядом.
- Кружку «+N» добавьте скрытое пояснение: `+5<span className="sr-only"> участников</span>`.
- Фокус аватар не получает. Кликабельный аватар оберните в кнопку или ссылку со своим именем.

## Локализация

Своих строк компонент не рисует: инициалы, `alt` и подписи — ваши.
