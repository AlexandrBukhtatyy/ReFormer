# Empty

Блок для места, где пока ничего нет: пустой список, пустой результат поиска, первый запуск.
Показывает иконку, заголовок, пояснение и кнопку следующего шага по центру. Собирается из частей,
любую можно опустить.

## Когда брать

- **Empty** — данные загружены, но их ноль, и пользователю нужно объяснить, что делать дальше.
- [AsyncBoundary](./async-boundary.mdx) — данные ещё грузятся или не загрузились. Для пустого,
  но успешного результата у него есть `AsyncBoundaryEmpty` — готовая сборка из частей Empty с
  рамкой и заголовком «Нет данных» по умолчанию.
- [Alert](./alert.mdx) — сообщение о проблеме или важном событии рядом с содержимым, а не вместо
  него.
- [Skeleton](./skeleton.mdx) — серая заглушка на месте содержимого, пока оно грузится.

## Анатомия

```tsx
import {
  Button,
  Empty,
  EmptyContent,
  EmptyDescription,
  EmptyHeader,
  EmptyMedia,
  EmptyTitle,
} from '@reformer/ui-kit'; // или '@reformer/ui-kit/empty'
import { FolderPlus } from 'lucide-react';

<Empty className="border">
  <EmptyHeader>
    <EmptyMedia variant="icon">
      <FolderPlus />
    </EmptyMedia>
    <EmptyTitle>Проектов пока нет</EmptyTitle>
    <EmptyDescription>Создайте первый проект, чтобы начать работу.</EmptyDescription>
  </EmptyHeader>
  <EmptyContent>
    <Button>Создать проект</Button>
  </EmptyContent>
</Empty>;
```

| Часть              | Что это                                                               | Ключевые пропсы                 |
| ------------------ | --------------------------------------------------------------------- | ------------------------------- |
| `Empty`            | Корень: всё по центру столбцом, с отступами. Растягивается по высоте. | `className`                     |
| `EmptyHeader`      | Группа медиа, заголовка и описания.                                   | —                               |
| `EmptyMedia`       | Иконка или иллюстрация над заголовком.                                | `variant`: `default` или `icon` |
| `EmptyTitle`       | Заголовок (`div`).                                                    | —                               |
| `EmptyDescription` | Пояснение приглушённым цветом. Ссылки внутри подчёркиваются.          | —                               |
| `EmptyContent`     | Действия под текстом: кнопки, поле ввода.                             | —                               |

- `EmptyMedia variant="icon"` — квадрат 40px с серым фоном, иконка внутри получает размер 24px.
  `variant="default"` — слот без фона: размер иконки или картинки задаёте сами.
- Стиль рамки у `Empty` пунктирный, но толщины у рамки нет. Видимую рамку включает класс
  `border`.
- `Empty` растягивается на свободное место во flex-контейнере (`flex-1`). В обычном блоке высоту
  ему даёт содержимое.
- `emptyMediaVariants` — классы медиа-слота (cva) для своего элемента с тем же видом.

## Доступность

- Все части — обычные `div` без ролей. Скринридер читает их как текст по порядку.
- `EmptyTitle` — не заголовок. Если блок должен попадать в навигацию по заголовкам, задайте
  `role="heading"` и `aria-level`.
- Empty, который появился после действия пользователя (поиск ничего не нашёл), скринридер сам не
  объявит. Оберните его в элемент с `role="status"`, если об этом важно сообщить.
- Иконки lucide без подписи сами получают `aria-hidden="true"`. Своей иллюстрации задайте `alt`
  или `alt=""`, если она декоративная.

## Локализация

Своих строк компонент не рисует: заголовок, пояснение и подписи кнопок — ваш текст.
