Дерево строк, каким его показывает файловый навигатор редактора: уровни с отступами, треугольник
у ветки, значок, подпись, метка справа. Показывает иерархию — файлы проекта, разделы каталога,
оргструктуру. Это навигация, а не поле формы: значения у дерева нет.

## Когда брать

- **Tree** — иерархию нужно смотреть и обходить: панель файлов, дерево ресурсов, навигатор
  разделов. Выбор строки — не единственная задача.
- `ComboboxTree` и `ComboboxTreeMulti` со страницы [Combobox](./combobox.mdx) — форме нужно
  значение из иерархии: один файл (`string | null`) или несколько (`string[] | null`). Внутри
  поповера у них это же дерево, а наружу — обычное поле формы.
- [Accordion](./accordion.mdx) — несколько крупных секций с текстом, а не плотный ряд строк.
- [List](./list.mdx) или [Item](./item.mdx) — плоский список без уровней.

Класть Tree в [схему формы](../reference/glossary.md) как поле (`component: Tree`) нельзя: у него
нет ни `value`, ни `onChange`.

## Анатомия

Tree — один компонент. Строки он рисует сам по данным узлов.

```tsx
import { Tree, type TreeNode } from '@reformer/ui-kit'; // или '@reformer/ui-kit/tree'

const nodes: TreeNode[] = [
  {
    id: 'src',
    label: 'src',
    kind: 'branch',
    children: [{ id: 'src/index.ts', label: 'index.ts' }],
  },
  { id: 'package.json', label: 'package.json' },
];

<Tree nodes={nodes} defaultExpandedIds={['src']} aria-label="Файлы проекта" className="h-full" />;
```

### Узел

| Поле                 | Что это                                                                                    |
| -------------------- | ------------------------------------------------------------------------------------------ |
| `id`                 | Адрес узла, уникальный во всём дереве. Для файлов — полный путь, а не имя.                 |
| `label`              | Подпись строки. По ней же идёт поиск.                                                      |
| `kind`               | `'branch'` или `'leaf'`. Объявляйте у веток явно: иначе пустой каталог неотличим от файла. |
| `children`           | Дети ветки. `undefined` значит «уровень ещё не прочитан», а не «детей нет».                |
| `badge`, `badgeTone` | Метка справа и её тон: `default`, `secondary`, `destructive`, `outline`.                   |
| `title`              | Подсказка при наведении. По умолчанию — `label`.                                           |
| `disabled`           | Строку нельзя выбрать. Раскрыть ветку можно.                                               |
| `loading`, `failed`  | Уровень читается / не прочитался. Для деревьев, которые читают уровни своим кодом.         |

### Откуда берутся узлы

- `nodes` — дерево известно целиком.
- `loadChildren(node)` — уровень читается при первом раскрытии ветки. Без `nodes` дерево читает и
  верхний уровень, передав `null`. С `nodes` верхний уровень берётся из них, а ветки без
  `children` дочитываются загрузчиком.
- Прочитанный уровень запоминается: свернуть и раскрыть ветку снова запроса не стоит. Перечитать
  уровень — метод `refresh(id)` у ссылки на дерево (`ref`).

### Выделение и отмеченный набор

Это два разных состояния, и у каждого есть управляемая пара пропсов:

- **выделение** (`selectedId`) — «где я сейчас»: одна строка, на ней фокус;
- **отмеченный набор** (`checkedIds`) — «что я выбрал»: сколько угодно строк при
  `selectionMode="multiple"`.

Как строка попадает в набор, задаёт `checkOn`:

| `checkOn`             | Щелчок             | `Ctrl`/`Cmd` + щелчок | `Shift` + щелчок | Пробел        | `Escape`      |
| --------------------- | ------------------ | --------------------- | ---------------- | ------------- | ------------- |
| `'modifier'` (умолч.) | заменяет набор     | добавляет или убирает | диапазон         | запуск строки | снимает набор |
| `'click'`             | переключает строку | —                     | —                | переключает   | уходит наружу |

`'modifier'` — привычка файлового менеджера, `'click'` — выбор из списка (например, в поповере, где
`Escape` закрывает поповер). `selectable="leaf"` разрешает выбирать только листья: щелчок по ветке
её раскрывает. Щелчок по ветке в любом режиме раскрывает или сворачивает её; `onActivate` для
веток не вызывается.

### Высота и виртуальный скролл

Виртуальный скролл включён по умолчанию: в разметке живут только видимые строки, а строки
фиксированной высоты (`rowHeight`, 24 px). Для этого дереву нужна определённая высота:

- `maxRows` — высота по содержимому, но не больше N строк. Удобно в поповере;
- `className` — высоту задаёт родитель, например `h-full` в панели.

При отрисовке на сервере размеров окна нет, и в разметку попадут только первые несколько строк.
Если разметка нужна целиком, ставьте `virtualized={false}` — так сделаны примеры на этой странице.

### Ссылка на дерево

`ref` с типом `TreeHandle` даёт `expand(id)`, `collapse(id)`, `toggle(id)`, `refresh(id)`,
`focusNode(id)`, `getRows()` и `getActionTargets()`, а также `focus()` и `blur()`.
`getActionTargets()` отвечает, к чему применить действие: к набору, если выделенная строка в нём,
иначе к одной выделенной строке.

## Доступность

Контейнер — `role="tree"`, строки — `role="treeitem"` с `aria-level`, `aria-selected`,
`aria-expanded` у веток и `aria-disabled` у недоступных. При `selectionMode="multiple"` дерево
помечено `aria-multiselectable`. Подпись дереву задайте сами: `aria-label` или `aria-labelledby`.

В дерево входят одним `Tab`: фокус встаёт на выделенную строку, а если её нет — на само дерево.
Дальше работает клавиатура:

| Клавиша        | Действие                                                                       |
| -------------- | ------------------------------------------------------------------------------ |
| `↓` / `↑`      | Следующая / предыдущая строка.                                                 |
| `→`            | Раскрыть свёрнутую ветку; у раскрытой ветки и листа — перейти на строку ниже.  |
| `←`            | Свернуть раскрытую ветку; иначе перейти к родителю.                            |
| `Home` / `End` | Первая / последняя строка.                                                     |
| `Enter`        | Запуск строки: `onActivate` с `preview: false`. Ветку — раскрыть или свернуть. |
| Пробел         | Запуск с `preview: true`; при `checkOn="click"` — переключить строку в наборе. |
| `Escape`       | При `checkOn="modifier"` снять набор; иначе событие уходит наружу.             |

- Дерево перехватывает эти клавиши и не пропускает их дальше. Сочетания с `Ctrl`, `Cmd` или `Alt`
  оно не трогает — они достаются сочетаниям приложения.
- Треугольник — не отдельная кнопка: он скрыт от скринридера, а состояние ветки объявлено на
  строке через `aria-expanded`.
- Контейнер строк — без своей роли (`role="none"`): между `tree` и `treeitem` нет чужих ролей, и
  скринридер связывает строки с деревом.

## Локализация

| Ключ             | English | Русский | Проп-замена |
| ---------------- | ------- | ------- | ----------- |
| `kit.tree.empty` | Empty   | Пусто   | `emptyText` |

Текст пустого дерева показывается, когда узлов нет или поиск ничего не нашёл. Остальные подписи —
ваши данные (`label`, `badge`, `title`).

Строка берётся из локали провайдера `I18nProvider` (`@reformer/core/react`); без провайдера она
английская. Русский набор кита — `ru` из `@reformer/ui-kit/locale/ru` или загрузчик
`loadKitLocale` из `@reformer/ui-kit/locale`. Заменить строку во всём приложении — ключом в своей
локали: `extendLocale(ru, { messages: { 'kit.tree.empty': 'Нет файлов' } })` из
`@reformer/core/i18n`. Только у одного дерева — пропом `emptyText`.
