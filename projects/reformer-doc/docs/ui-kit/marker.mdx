# Marker

Служебная строка в ленте чата: статус ассистента, шаг рассуждения, разделитель «Сегодня»,
заголовок блока источников. Текст приглушён, чтобы не спорить с репликами. Оформление задаёт
`variant`.

## Когда брать

- **Marker** — короткая строка о ходе диалога, а не реплика: «Ассистент ищет тарифы»,
  «Источники».
- [Bubble](./bubble.mdx) — сама реплика пользователя или ассистента.
- [Badge](./badge.mdx) — короткая метка внутри строки или карточки, а не строка на всю ширину.
- [Item](./item.mdx) — полноценная строка списка с заголовком, описанием и действиями.

## Анатомия

```tsx
import { Marker, MarkerIcon, MarkerContent } from '@reformer/ui-kit';
// или '@reformer/ui-kit/marker'
import { Sparkles } from 'lucide-react';

<Marker variant="default">
  <MarkerIcon>
    <Sparkles />
  </MarkerIcon>
  <MarkerContent>Ассистент ищет подходящие тарифы</MarkerContent>
</Marker>;
```

| Часть           | Что это                                      | Ключевые пропсы      |
| --------------- | -------------------------------------------- | -------------------- |
| `Marker`        | Строка на всю ширину с приглушённым текстом. | `variant`, `asChild` |
| `MarkerIcon`    | Значок 16×16 px слева. Скрыт от скринридера. | `children` — значок  |
| `MarkerContent` | Текст строки. Ссылки внутри подчёркнуты.     | `children`           |

Варианты `variant`:

- `default` — значок и текст в строку;
- `separator` — текст по центру, по бокам горизонтальные линии;
- `border` — линия под строкой, для заголовка блока.

`asChild` отдаёт оформление дочернему элементу: с `<a>` внутри кликабельна вся строка.

## Доступность

- `Marker` — обычный `div` (или ваш элемент при `asChild`), своей роли нет. Если статус меняется
  на лету («Ищу…» → «Готово»), а сообщить о нём нужно скринридеру, поставьте на строку
  `role="status"`.
- `MarkerIcon` помечен `aria-hidden="true"`: значок не читается. Не кладите в него смысл, которого
  нет в тексте, — например номер источника.
- Ссылка через `asChild` получает обычную клавиатуру ссылки: `Tab` и `Enter`.

## Локализация

Своих строк компонент не рисует: текст строки — ваш.
