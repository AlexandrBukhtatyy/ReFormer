# FormField

<ComponentDoc config={uiKitFormFieldDocConfig}>
Обёртка поля. Получает [ноду](../reference/glossary.md#форма-и-данные) поля и рисует вокруг
контрола подпись, пояснение и [замечание](../reference/glossary.md#валидация). Какой контрол
рисовать и с какими пропсами, FormField берёт из узла схемы — в разметке остаётся одна строка
`<FormField control={form.email} />`.

## Когда брать

- **Разметка руками** — `<FormField control={form.x} />` на каждое поле.
- **Форма по схеме** — FormField становится обёрткой поля рендерера:
  `<FormRenderer form={bundle} settings={{ fieldWrapper: FormField }} />`.

Соседи:

- нужна своя раскладка подписи, контрола и замечания — слоты
  [FormField из cdk](/docs/cdk/form-field), на которых построен этот компонент;
- поле, которым управляет не форма ReFormer, или вёрстка без формы —
  [Field](./field.mdx) и [Label](./label.mdx);
- массив под-форм — [FieldArraySection](./field-array.mdx).

## Анатомия

Сверху вниз FormField рисует четыре зоны:

| Зона      | Откуда берётся                                   |
| --------- | ------------------------------------------------ |
| Подпись   | `componentProps.label`, звёздочка — `required`   |
| Контрол   | `component` и его пропсы из узла схемы           |
| Пояснение | `componentProps.description`                     |
| Замечание | первое замечание правил поля, текст — из словаря |

Замечание видно, когда поле тронуто или изменено. Под полем показывается одно: первая ошибка, а
если ошибок нет — первое предупреждение. Предупреждение (`severity: 'warning'`) рисуется своим
цветом и не делает поле невалидным. Пока идёт асинхронная проверка, под полем стоит «Проверка...».

У `CheckboxWithLabel` и `SwitchWithLabel` подпись стоит справа от контрола и рисуется самим
контролом, поэтому верхней подписи у них нет. `label` и `required` FormField отдаёт им, и
звёздочку они рисуют у своей подписи. Остальным контролам `label`, `description`, `required` и
`labelTooltip` не передаются: их рисует FormField.

Пропсы самого FormField — `control`, `direction`, `testId`, `className`, `children` — описаны на
вкладке API.

### Общие пропсы полей

Эти ключи понимает узел любого поля кита. Их пишут в `componentProps` рядом с пропсами
компонента:

| Проп           | Что делает                                                                                     |
| -------------- | ---------------------------------------------------------------------------------------------- |
| `label`        | Подпись поля.                                                                                  |
| `required`     | Звёздочка у подписи и `aria-required`. Само правило `required()` — в схеме валидации.          |
| `description`  | Пояснение под контролом.                                                                       |
| `labelTooltip` | Иконка (i) с подсказкой после подписи.                                                         |
| `tooltip`      | Иконка (i) внутри контрола: у полей ввода и списков — справа внутри, у флажков — после текста. |
| `testId`       | Префикс `data-testid`: `field-`, `label-`, `input-`, `error-<id>`.                             |

```tsx
{
  model: model.$.inn,
  component: Input,
  componentProps: {
    label: 'ИНН',
    required: true,
    description: 'Для юрлица — 10 цифр, для ИП — 12',
    labelTooltip: 'Есть в выписке из ЕГРЮЛ',
    testId: 'inn',
  },
}
```

`value`, `onChange`, `onBlur` и `disabled` в `componentProps` не пишут: их подставляет FormField
из ноды. Заблокировать поле — `form.inn.disable()`.

`description` и `labelTooltip` FormField читает один раз, при первом показе поля. Чтобы сменить их
на лету, пересоздайте поле. `label` и `required` меняются на лету через
`form.inn.updateComponentProps({ label })`.

## Доступность

- Подпись — настоящий `<label for>`, и контрол ссылается на неё через `aria-labelledby`. У
  `CheckboxWithLabel` и `SwitchWithLabel` имя даёт их собственная подпись `<label for>`.
- Пояснение, текст `labelTooltip` и показанное замечание связаны с контролом через
  `aria-describedby` — скринридер прочитает их вместе с подписью.
- Пока на экране ошибка, у контрола стоят `aria-invalid` и `aria-errormessage`. Предупреждение
  `aria-invalid` не ставит.
- При `required` у контрола стоит `aria-required`; звёздочка у подписи скрыта от скринридера.
- Замечание выводится с `role="alert"`, статус «Проверка...» — с `role="status"`, поэтому
  скринридер объявляет их сам.
- Иконка `labelTooltip` — кнопка с подписью вида «Подсказка: Email». Она стоит вне `<label>`,
  поэтому нажатие по ней не переводит фокус в контрол.

## Локализация

FormField рисует две свои строки:

| Ключ                       | По-русски           | Где                                           |
| -------------------------- | ------------------- | --------------------------------------------- |
| `kit.formField.validating` | Проверка...         | статус асинхронной проверки под полем         |
| `kit.formField.hintLabel`  | Подсказка: \{label} | подпись иконки `labelTooltip` для скринридера |

Подпись, пояснение и подсказки задаёте вы в `componentProps`. Тексты замечаний — из
[словаря сообщений](../reference/glossary.md#валидация): словаря формы
(`ValidationMessagesProvider` из `@reformer/cdk`) или словаря языка. Как включить русскую локаль
кита — в [обзоре](./overview.md#локализация).
