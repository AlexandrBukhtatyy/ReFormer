Плашка с сообщением: заголовок, текст и необязательная иконка слева. Вид — `variant`: сведения
(`default`) или ошибка (`destructive`). Компонент входит в
[кит](../reference/glossary.md#пакеты) `@reformer/ui-kit`, это не поле формы.

## Когда брать

- **Alert** — сообщение, которое остаётся на странице: «Что будет дальше», «Не удалось загрузить
  тарифы».
- [Sonner](./sonner.mdx) — короткое уведомление, которое само исчезнет через несколько секунд.
- [AlertDialog](./alert-dialog.mdx) — нужно решение человека, прежде чем продолжить.
- Ошибка одного поля — её показывает [FormField](./form-field.mdx) под полем; Alert для этого не
  нужен.
- [Empty](./empty.mdx) — пустое состояние списка или раздела.

Не делайте плашку цветными классами (`bg-yellow-50 border-yellow-200`): ручная палитра ломает
тёмную тему.

## Анатомия

```tsx
import { Alert, AlertTitle, AlertDescription } from '@reformer/ui-kit'; // или '@reformer/ui-kit/alert'
import { CircleAlert } from 'lucide-react';

<Alert variant="destructive">
  <CircleAlert />
  <AlertTitle>Ошибка платежа</AlertTitle>
  <AlertDescription>Проверьте данные карты и попробуйте снова.</AlertDescription>
</Alert>;
```

| Часть              | Что это                                                          | Ключевые пропсы   |
| ------------------ | ---------------------------------------------------------------- | ----------------- |
| `Alert`            | Корень с рамкой. Иконка первым элементом встаёт в колонку слева. | `variant`, `role` |
| `AlertTitle`       | Заголовок в одну строку (длинный обрезается).                    | —                 |
| `AlertDescription` | Текст сообщения; абзацы внутри получают межстрочный интервал.    | —                 |

`variant` принимает `default` и `destructive`. Иконка берёт цвет текста плашки. Все части — `<div>`
и принимают `className`.

## Доступность

- У `variant="destructive"` корень получает `role="alert"`: появившись на странице, плашка сразу
  зачитывается скринридером и перебивает то, что он читал. Это правильно для ошибки, которая
  возникла после действия.
- У `variant="default"` живой роли нет: постоянное пояснение скринридер не объявляет как срочное.
  Сообщению, которое появляется в ответ на действие («Сохранено»), задайте `role="status"`. Проп
  `role` перекрывает значение по умолчанию у обоих видов.
- Вид `destructive` отличается только цветом. Напишите в заголовке, что это ошибка, — цвет видят
  не все.
- Иконка — украшение: иконки lucide по умолчанию скрыты от скринридера (`aria-hidden`).
- Фокус плашка не получает. Если в ней есть кнопка «Повторить», фокус на неё переводите сами.

## Локализация

Своих строк компонент не рисует: заголовок и текст — ваши.
