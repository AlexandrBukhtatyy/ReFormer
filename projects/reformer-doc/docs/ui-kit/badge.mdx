# Badge

<ComponentDoc config={badgeDocConfig}>
Короткая метка рядом с текстом: статус заявки, число непрочитанных, тег. Вид задаёт `variant`.
Компонент входит в [кит](../reference/glossary.md#пакеты) `@reformer/ui-kit`, это не поле формы.

## Когда брать

- **Badge** — одно-два слова или число, которые уточняют соседний текст: «черновик», «12», «PRO».
- [Button](./button.mdx) — если по метке нужно что-то сделать. Метку-ссылку даёт `asChild`, но
  действие на странице — это кнопка.
- [Alert](./alert.mdx) — сообщение из предложения или двух, а не ярлык.
- [Kbd](./kbd.mdx) — клавиша или сочетание клавиш.
- `AvatarBadge` из [Avatar](./avatar.mdx) — точка статуса в углу аватара.

## Анатомия

```tsx
import { Badge } from '@reformer/ui-kit'; // или '@reformer/ui-kit/badge'

<Badge variant="outline">черновик</Badge>;
```

Это один элемент `<span>`. Иконка внутри получает размер 12px сама.

| Проп      | Значения                                                          | По умолчанию | Что делает                                                |
| --------- | ----------------------------------------------------------------- | ------------ | --------------------------------------------------------- |
| `variant` | `default`, `secondary`, `destructive`, `outline`, `ghost`, `link` | `default`    | Вид метки.                                                |
| `asChild` | `boolean`                                                         | `false`      | Отрисовать вместо `<span>` единственный дочерний элемент. |

Подсветка при наведении у вариантов включается только на ссылке (`asChild` с `<a>`): обычная
метка на курсор не реагирует.

## Доступность

- Метка — обычный текст в `<span>`: скринридер читает её вместе с соседним текстом, роли и фокуса у
  неё нет.
- Смысл не должен держаться только на цвете. «12» красным и «12» серым читаются одинаково — если
  важен статус, напишите его словом («просрочено»).
- Число без контекста («12») ставьте рядом с подписью («Входящие») или дайте метке `aria-label`.
- Метка-ссылка (`asChild` с `<a>`) получает фокус и кольцо фокуса как обычная ссылка.

## Локализация

Своих строк компонент не рисует: текст метки — ваш.
