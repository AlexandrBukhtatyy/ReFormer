# InputOTP

<ComponentDoc config={inputOtpDocConfig}>
Поле одноразового кода: каждый символ — в своей ячейке. Работает на библиотеке
[`input-otp`](https://input-otp.rodz.dev/). Для формы — `InputOTPDefault`, он кладётся в
`component` [узла схемы](../reference/glossary.md#форма-и-данные) как есть.

Компонент импортируется только из входа пакета `@reformer/ui-kit/input-otp`. Ему нужна
необязательная зависимость `input-otp` (версия 1.4 и выше) — поставьте её в проект.

## Когда брать

- Код подтверждения из СМС или письма, код двухфакторного входа, PIN — короткая строка
  фиксированной длины.

Соседи:

- строка с шаблоном, но не по ячейкам (телефон, номер карты) — [InputMask](./input-mask.mdx);
- пароль произвольной длины — [InputPassword](./input-password.mdx).

## Анатомия

| Компонент         | Значение поля    | Ключевые пропсы                                                    |
| ----------------- | ---------------- | ------------------------------------------------------------------ |
| `InputOTPDefault` | `string \| null` | `maxLength` (по умолчанию 6), `pattern`, `inputMode`, `onComplete` |

`InputOTPDefault` рисует одну группу из `maxLength` ячеек. Пустое поле даёт `null`, набранная
часть кода — строку короче `maxLength`. Проверить, что код набран целиком, — правило
`minLength(6)` в [схеме валидации](../reference/glossary.md#валидация).

По умолчанию ячейки принимают любые символы, а на телефоне открывается цифровая клавиатура
(`inputMode: 'numeric'`; другую задаёт тот же проп). Ограничить набор — пропом `pattern`:
строкой регулярного выражения для всего кода. Готовые значения экспортирует
`@reformer/ui-kit/input-otp`: `REGEXP_ONLY_DIGITS` — только цифры, `REGEXP_ONLY_CHARS` — только
латинские буквы, `REGEXP_ONLY_DIGITS_AND_CHARS` — цифры и латинские буквы. `pattern` и
`inputMode` есть в props-схеме, поэтому их принимает и
[документ renderer-json](/docs/packages/renderer-json).

`onComplete(value)` вызывается, когда заполнены все `maxLength` ячеек, — например, чтобы сразу
проверить код. Это функция, поэтому в документ renderer-json её не записать: только в схеме формы
в коде.

Своя раскладка — групп несколько, между ними разделитель — собирается из частей:

| Часть               | Что это                                                                                                             |
| ------------------- | ------------------------------------------------------------------------------------------------------------------- |
| `InputOTP`          | Корень: скрытое настоящее поле и контекст ячеек. Пропсы `maxLength`, `value`, `onChange(value: string)`, `pattern`. |
| `InputOTPGroup`     | Группа ячеек, стоящих вплотную.                                                                                     |
| `InputOTPSlot`      | Ячейка; `index` — номер символа в коде, с нуля.                                                                     |
| `InputOTPSeparator` | Разделитель между группами (`role="separator"`).                                                                    |

Части — примитив вне формы: `onChange` получает строку как есть, пустое поле даёт `''`, а не
`null`.

Кроме своих пропсов, поле понимает общие для всех полей кита: `label`, `required`, `description`,
`labelTooltip`, `tooltip`, `testId` — см. [FormField](./form-field.mdx#общие-пропсы-полей). Иконка
`tooltip` встаёт справа от ячеек.

```tsx
import { InputOTPDefault } from '@reformer/ui-kit/input-otp';

{
  model: model.$.otp,
  component: InputOTPDefault,
  componentProps: { label: 'Код подтверждения', maxLength: 6 },
}
```

## Доступность

- Под ячейками — одно настоящее `<input>`, видимое скринридеру и браузеру. Ячейки только рисуют
  его содержимое.
- У поля стоит `autocomplete="one-time-code"`: браузер и телефон предлагают код из СМС. Вставка
  кода целиком тоже работает.
- Стрелки ←/→ двигают курсор по ячейкам, Backspace стирает символ.
- `FormField` связывает поле с подписью (`aria-labelledby`), пояснением и замечанием
  (`aria-describedby`). Пока замечание показано, у поля стоят `aria-invalid` и
  `aria-errormessage`; при `required` — `aria-required`.

## Локализация

Своих строк `InputOTP` не рисует. Встроенная строка одна — подпись кнопки-иконки `tooltip` для
скринридера, ключ `kit.infoHint.label` («Подсказка»). Тексты замечаний берутся из
[словаря сообщений](../reference/glossary.md#валидация) формы. Как подключить русскую локаль
кита — в [обзоре](./overview.md#локализация).
