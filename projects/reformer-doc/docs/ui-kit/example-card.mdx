# ExampleCard

Карточка для демо-страниц и песочниц: заголовок, описание и живой пример. Кнопка в шапке
переключает карточку на код примера, а кнопка в углу кода копирует его. Компонент входит в
[кит](../reference/glossary.md#пакеты) `@reformer/ui-kit`, это не поле формы.

## Когда брать

- **ExampleCard** — каталог компонентов, внутренняя песочница, страница «как это выглядит».
- В рабочем интерфейсе — нет: переключатель «пример ↔ код» не настраивается, а оформление кода
  рассчитано на демо. Для блока с рамкой берите [Card](./card.mdx).

## Анатомия

```tsx
import { ExampleCard, Button } from '@reformer/ui-kit'; // или '@reformer/ui-kit/example-card'

<ExampleCard
  title="Опасное действие"
  description="Кнопка удаления"
  code={`<Button variant="destructive">Удалить</Button>`}
>
  <Button variant="destructive">Удалить</Button>
</ExampleCard>;
```

| Проп          | Тип         | Что делает                                                 |
| ------------- | ----------- | ---------------------------------------------------------- |
| `title`       | `string`    | Заголовок, обязателен. Рисуется тегом `h3`.                |
| `description` | `string`    | Строка под заголовком.                                     |
| `children`    | `ReactNode` | Живой пример — виден, пока карточка не переключена на код. |
| `code`        | `string`    | Текст кода для режима «код» и для копирования.             |
| `bgColor`     | `string`    | Класс фона, по умолчанию `bg-card`.                        |
| `className`   | `string`    | Дополнительные классы корня.                               |

`code` — просто строка. Карточка его не выполняет и не сверяет с `children`: следить, чтобы пример
и код совпадали, приходится вам. Для фона берите цвета темы (`bg-muted`, `bg-accent`) — они верны и
в тёмной теме.

## Доступность

- Заголовок карточки — `h3`. Ставьте карточки под заголовком `h2`, чтобы структура страницы не
  ломалась.
- Обе кнопки — иконки без текста. Кнопка «пример ↔ код» — переключатель: имя постоянное
  («Показать код», `aria-label`), а режим кода скринридер узнаёт по `aria-pressed`. Всплывающая
  подсказка `title` меняется: «Показать код» / «Показать пример». Кнопке копирования имя даёт
  `title` («Копировать код»).
- Что код скопирован, видно только по смене иконки — скринридер этого не объявляет.
- Обе кнопки — `type="button"`: внутри `<form>` они форму не отправляют.

## Локализация

Подписи кнопок кит рисует сам:

| Ключ словаря                  | English      | Русский         |
| ----------------------------- | ------------ | --------------- |
| `kit.exampleCard.showCode`    | Show code    | Показать код    |
| `kit.exampleCard.showPreview` | Show example | Показать пример |
| `kit.exampleCard.copy`        | Copy code    | Копировать код  |
| `kit.exampleCard.copied`      | Copied!      | Скопировано!    |

Пропсов для этих подписей нет. Язык берётся из `I18nProvider` (`@reformer/core/react`) с локалью
кита `loadKitLocale` из `@reformer/ui-kit/locale`; без провайдера подписи английские. Свою
формулировку задаёт источник словаря после `loadKitLocale`:

```tsx
import { createLocaleLoader } from '@reformer/core/i18n';
import { loadKitLocale } from '@reformer/ui-kit/locale';

const loadLocale = createLocaleLoader([
  loadKitLocale,
  (code) => (code === 'ru' ? { 'kit.exampleCard.showCode': 'Код' } : null),
]);
```
