# Sonner

Всплывающие уведомления в углу экрана: «Сохранено», «Не удалось отправить». Через несколько
секунд они исчезают сами. Контейнер `Toaster` ставится один раз в корне приложения, а уведомление
показывает функция `toast()` из любого места кода. Построено на
[sonner](https://sonner.emilkowal.ski/) и входит в [кит](../reference/glossary.md#пакеты)
`@reformer/ui-kit`, это не поле формы.

Компонент тянет внешнюю библиотеку, поэтому в общий импорт `@reformer/ui-kit` не входит. Поставьте
зависимость и импортируйте из отдельного входа:

```bash
npm install sonner
```

```tsx
import { Toaster, toast } from '@reformer/ui-kit/sonner';
```

## Когда брать

- **Sonner** — короткий итог действия, который не требует ответа: «Заявка отправлена», «Ссылка
  скопирована», «Удалено — Отменить».
- [Alert](./alert.mdx) — сообщение должно остаться на странице: ошибка загрузки, условие, которое
  надо прочитать.
- [AlertDialog](./alert-dialog.mdx) — нужно решение человека до продолжения.
- Ошибки полей формы показывает [FormField](./form-field.mdx) под каждым полем, а не уведомление.

## Анатомия

```tsx
import { Toaster, toast } from '@reformer/ui-kit/sonner';

// Один раз у корня приложения:
<Toaster position="top-center" richColors />;

// Где угодно:
toast.success('Заявка отправлена', { description: 'Ответ придёт на почту в течение дня.' });
```

| Что                                                   | Для чего                                               |
| ----------------------------------------------------- | ------------------------------------------------------ |
| `Toaster`                                             | Контейнер уведомлений. Один на приложение.             |
| `toast(message, options?)`                            | Показать уведомление; возвращает id.                   |
| `toast.success` / `error` / `warning` / `info`        | Уведомление со статусом и своей иконкой.               |
| `toast.promise(promise, { loading, success, error })` | «Загрузка», которая сама сменится на успех или ошибку. |
| `toast.dismiss(id?)`                                  | Убрать одно уведомление или все.                       |

Пропсы `Toaster`: `position` (`bottom-right`), `richColors` — заливка цветом статуса, `expand`,
`closeButton`, `duration` (4000 мс), `theme`. В `options` вызова: `description` — вторая строка,
`action: { label, onClick }` — кнопка в уведомлении, `duration`, `id` — чтобы обновить уведомление
вместо нового.

- `toast()` показывает уведомление во всех смонтированных `Toaster` сразу. Два контейнера на
  странице — два одинаковых уведомления.
- Без `theme` уведомления берут тему приложения: тёмную, если выше по дереву стоит класс `.dark`
  или атрибут `[data-theme='dark']`, иначе светлую. Переключение темы подхватывается само. `theme`
  задаёт тему явно, `theme="system"` — по настройке ОС.
- Свои `toastOptions`, `icons` и `style` дополняют настройки кита, а не заменяют их: например,
  свой `toastOptions.duration` не сбрасывает иконки статусов и их выравнивание.

## Доступность

| Клавиша | Действие                                                                   |
| ------- | -------------------------------------------------------------------------- |
| `Alt+T` | Раскрыть стопку и перейти к уведомлениям (сочетание задаёт проп `hotkey`). |
| `Tab`   | По кнопкам внутри уведомлений.                                             |
| `Esc`   | Свернуть стопку, пока фокус в ней.                                         |

- Область уведомлений — `aria-live="polite"`: скринридер читает новое уведомление, не прерывая
  текущее чтение.
- Пока курсор над уведомлениями или фокус в них, таймер скрытия стоит.
- Уведомление исчезает само. Не кладите в него единственную копию важного и действия, у которых нет
  другого пути, — человек может не успеть. Для долгого показа задайте `duration` или берите
  [Alert](./alert.mdx).

## Локализация

Текст уведомлений — ваш. Две служебные подписи для скринридера `Toaster` берёт из словаря кита:

| Ключ               | English         | Русский               | Где                             | Чем заменить в компоненте           |
| ------------------ | --------------- | --------------------- | ------------------------------- | ----------------------------------- |
| `kit.sonner.label` | `Notifications` | `Уведомления`         | Имя области уведомлений.        | `containerAriaLabel`                |
| `kit.sonner.close` | `Close toast`   | `Закрыть уведомление` | Имя крестика при `closeButton`. | `toastOptions.closeButtonAriaLabel` |

Строки берутся из локали, которую задаёт `I18nProvider` из `@reformer/core/react`; без провайдера
— английские. Русский набор кита — `ru` из `@reformer/ui-kit/locale/ru` или загрузчик
`loadKitLocale` из `@reformer/ui-kit/locale`.
