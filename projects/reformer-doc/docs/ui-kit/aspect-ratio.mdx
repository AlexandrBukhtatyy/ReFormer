Область с постоянной пропорцией ширины к высоте. Ширину задаёт родитель, высоту компонент
считает сам. Поэтому место под картинку или видео зарезервировано заранее, и страница не прыгает,
пока они грузятся. Построен на Radix AspectRatio, это не поле формы.

## Когда брать

- **AspectRatio** — медиа должно сохранять пропорцию при любой ширине: обложка статьи, превью
  видео, карта, миниатюра товара.
- Фиксированная высота (`h-40`) — если ширина блока тоже фиксирована: пропорция тогда не нужна.
- [Avatar](./avatar.mdx) — круглое фото пользователя с запасным вариантом из инициалов.
- [Skeleton](./skeleton.mdx) — серая заглушка на месте содержимого, пока оно грузится. Её можно
  положить внутрь AspectRatio.

## Анатомия

```tsx
import { AspectRatio } from '@reformer/ui-kit'; // или '@reformer/ui-kit/aspect-ratio'

<div className="w-80">
  <AspectRatio ratio={16 / 9} className="overflow-hidden rounded-md bg-muted">
    <img src="/cover.jpg" alt="Обложка статьи" className="h-full w-full object-cover" />
  </AspectRatio>
</div>;
```

AspectRatio — один компонент, но в разметке у него два элемента:

| Элемент          | Что делает                                                                                     |
| ---------------- | ---------------------------------------------------------------------------------------------- |
| Внешний `div`    | Занимает всю ширину родителя и получает высоту из пропорции. Пропсами не настраивается.        |
| Внутренний `div` | Растянут на весь внешний. Сюда попадают `children`, `className`, `style` и остальные атрибуты. |

| Проп        | Что делает                                                                   |
| ----------- | ---------------------------------------------------------------------------- |
| `ratio`     | Отношение ширины к высоте: `16 / 9`, `4 / 3`, `1`. По умолчанию `1`.         |
| `className` | Вид области: фон, скругление, `overflow-hidden` для картинки со скруглением. |

Ширину ставьте на родителя, а не на AspectRatio: внешний элемент всегда занимает её целиком.
Содержимое растягивайте на всю область — классы `h-full w-full`, для картинки ещё `object-cover`.

## Доступность

- Роли и клавиатуры у компонента нет: это обычные `div`.
- Текстовую альтернативу задаёте вы: `alt` у картинки, `title` у `iframe`. Декоративной картинке
  ставьте `alt=""`.

## Локализация

Своих строк компонент не рисует.
