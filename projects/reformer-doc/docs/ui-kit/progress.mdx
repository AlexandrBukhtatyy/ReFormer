Горизонтальная полоса, заполненная на долю `value / max`: загрузка файла, заполненность профиля,
доля пройденных шагов. Построена на Radix Progress и входит в
[кит](../reference/glossary.md#пакеты) `@reformer/ui-kit`, это не поле формы.

## Когда брать

- **Progress** — известна доля выполненного: 40 % файла загружено, 3 из 5 разделов заполнено.
- [Spinner](./spinner.mdx) — ожидание без известной доли: запрос к серверу.
- [Skeleton](./skeleton.mdx) — загрузка содержимого с известной раскладкой.
- [Slider](./slider.mdx) — значение, которое человек меняет сам. Progress только показывает.
- Индикатор шагов многошаговой формы рисует [FormWizard](./form-navigation.mdx).

## Анатомия

```tsx
import { Progress } from '@reformer/ui-kit'; // или '@reformer/ui-kit/progress'

<Progress value={40} aria-label="Загрузка файла" />;
```

Это дорожка (`Progress.Root` Radix) с заполнением внутри. Отдельных частей нет.

| Проп        | Тип      | Что делает                                                              |
| ----------- | -------- | ----------------------------------------------------------------------- |
| `value`     | `number` | Текущее значение от 0 до `max`. Без него (или вне шкалы) полоса пустая. |
| `max`       | `number` | Верх шкалы, по умолчанию 100. Заливка — доля `value / max`.             |
| `className` | `string` | Классы дорожки: высота `h-*`, ширина `w-*`, скругление.                 |

Шкалу можно задать своими единицами: `value={3} max={5}` заполнит полосу на 60 %, переводить в
проценты не нужно. Значение меньше 0 или больше `max` компонент считает неопределённым: полоса
пустая, как без `value`.

Подпись и число процентов компонент не рисует — ставьте их рядом (пример «Подпись и значение для
скринридера»).

## Доступность

- Radix ставит дорожке `role="progressbar"`, `aria-valuemin`, `aria-valuemax` и, если `value`
  задан, `aria-valuenow` и `aria-valuetext` — процент от `max` («60%»). Свой текст, например «3 из
  5 разделов», передайте в `aria-valuetext`.
- Без `value` прогресс неопределённый: `aria-valuenow` нет, у дорожки `data-state="indeterminate"`.
  С `value` — `data-state="loading"`, при `value` равном `max` — `"complete"`. По `data-state`
  можно стилизовать завершённую полосу.
- Дайте полосе имя: `aria-label` или `aria-labelledby` со ссылкой на видимую подпись.
- Фокус полоса не получает. О завершении сообщите текстом или уведомлением — изменение полосы
  скринридер сам не объявляет.

## Локализация

Своих строк компонент не рисует: подпись, проценты и `aria-valuetext` — ваши.
