# DirectionProvider

Сообщает компонентам на Radix, в какую сторону идёт текст: слева направо (`ltr`) или справа
налево (`rtl`, иврит и арабский). Своей разметки не рисует — только передаёт направление вниз по
дереву. Хук `useDirection` читает его в ваших компонентах.

## Когда брать

- **DirectionProvider** — приложение или его часть работает на языке с письмом справа налево.
  Компоненты кита на Radix развернут поведение: стрелки клавиатуры, сторону подменю, заполнение
  слайдера, сторону полосы прокрутки.
- Атрибут `dir` на HTML-элементе — для раскладки и выравнивания текста в CSS. Провайдер его не
  ставит, поэтому в rtl-приложении нужны оба: `dir="rtl"` на `<html>` (или корне раздела) и
  DirectionProvider над компонентами.
- Проп `dir` у отдельного компонента (`Accordion`, `ScrollArea` и других) — направление только для
  него. Он важнее провайдера.

## Анатомия

```tsx
import { DirectionProvider, useDirection } from '@reformer/ui-kit'; // или '@reformer/ui-kit/direction'

function App({ lang }: { lang: string }) {
  const dir = lang === 'he' || lang === 'ar' ? 'rtl' : 'ltr';
  return (
    <div dir={dir}>
      <DirectionProvider dir={dir}>{/* приложение */}</DirectionProvider>
    </div>
  );
}

function Toolbar() {
  const dir = useDirection(); // 'ltr' | 'rtl'
  // …
}
```

| Часть               | Что это                                                                | Ключевые пропсы                   |
| ------------------- | ---------------------------------------------------------------------- | --------------------------------- |
| `DirectionProvider` | React-контекст направления. В DOM ничего не добавляет.                 | `dir` или `direction`, `children` |
| `useDirection`      | Хук: проп-направление, если передан, иначе из провайдера, иначе `ltr`. | `localDir` — необязательный       |

- `direction` — второе имя пропа `dir`. Если заданы оба, побеждает `direction`.
- Направление читают компоненты кита на Radix: Accordion, Tabs, Menubar, NavigationMenu,
  DropdownMenu, ContextMenu, RadioGroup, ToggleGroup, Slider, ScrollArea и базовый Select.
- Вложенный провайдер переопределяет внешний для своего поддерева.

## Доступность

- Скринридер и браузер узнают направление из атрибута `dir` и языка из атрибута `lang` в DOM.
  Провайдер их не ставит — задайте `dir` и `lang` на `<html>` или корне раздела сами.
- Провайдер меняет поведение клавиатуры в компонентах на Radix: в горизонтальных списках при `rtl`
  стрелка `→` ведёт к предыдущему элементу, а `←` — к следующему. Так клавиши совпадают с
  направлением чтения.

## Локализация

Своих строк компонент не рисует. Направление в локали кита не хранится: выводите его из кода языка
сами, как в примере «Направление от языка».
