# FormWizard

Оформленная многошаговая форма — мастер. Рисует индикатор шагов, тело текущего шага, кнопки
«Назад», «Далее», «Отправить» и строку прогресса. Какие шаги есть и какие правила у каждого,
задаёт [поток шагов](../reference/glossary.md#поведение-шаги-и-отправка) сборки формы.

## Когда брать

- Длинная анкета, которую удобнее заполнять частями: заявка на кредит, регистрация компании.
- Каждый шаг нужно проверить, прежде чем пустить дальше.

Соседи:

- своя раскладка мастера (индикатор сбоку, кнопки в шапке) — [FormWizard из cdk](/docs/cdk/form-wizard):
  те же части без оформления;
- группы полей на одной странице без шагов — [Section](./section.mdx),
  [Accordion](./accordion.mdx) или [Tabs](./tabs.mdx);
- как устроены шаги, переходы и отправка — руководство
  [Многошаговые формы](../guides/multi-step-forms.mdx).

## Анатомия

Сверху вниз: индикатор шагов (`StepIndicator`) → карточка с телом шага → кнопки
(`FormWizardActions`) → прогресс «Шаг 2 из 3 • 67% завершено» (`FormWizardProgress`).

Шаги объявляются в потоке сборки. `id` шага связывает его с разметкой:

```ts
createForm<CreditForm>({
  initial,
  schema,
  flow: {
    steps: [
      { id: 'contact', rules: contactRules }, // правила шага — схема валидации
      { id: 'phone', rules: phoneRules },
      { id: 'confirm' }, // шаг без правил
    ],
  },
});
```

- **«Далее»** проверяет правила текущего шага. Есть замечания — мастер остаётся на шаге, поля
  шага показывают ошибки.
- **Индикатор** ведёт на первый шаг всегда, на остальные — после того как пройдены предыдущие.
- **«Отправить»** на последнем шаге проверяет форму целиком.

Подключить мастер можно двумя способами.

**В разметке** — передайте `form`, `flow` и массив `steps`. Тело шага — компонент
`({ control }) => …`, готовый ReactNode или узел схемы (с `renderStepBody`). `onSubmit` здесь
зовётся по нажатию, проверку и отправку делает сборка:

```tsx
<FormWizard
  form={bundle.form}
  flow={bundle.flow}
  steps={[
    { number: 1, title: 'Контакт', icon: '👤', body: ContactStep },
    { number: 2, title: 'Телефон', icon: '📞', body: PhoneStep },
  ]}
  onSubmit={() => void bundle.submission.submit(send)}
/>
```

**В схеме формы** — мастер становится узлом, шаги — его дочерними узлами `Step` из
`@reformer/cdk/form-wizard`. `selector` шага совпадает с `id` шага потока. Форму и поток мастер
берёт из сборки, которую рисует `FormRenderer`. Обработчик отправки вешается в поведении формы и
получает значения только после успешной проверки:

```tsx
{
  selector: 'wizard',
  component: FormWizard,
  componentProps: { submitLabel: 'Отправить заявку' },
  children: [
    { selector: 'contact', component: Step, componentProps: { title: 'Контакт', icon: '👤' }, children: [/* поля */] },
    { selector: 'phone', component: Step, componentProps: { title: 'Телефон', icon: '📞' }, children: [/* поля */] },
  ],
}

// в поведении формы:
onComponentEvent(schema.node('wizard'), 'onSubmit', (values) => api.send(values));
```

Если `selector` шага и `id` в потоке разошлись, в режиме разработки мастер пишет предупреждение
в консоль: шаг без разметки иначе потерялся бы молча.

Кнопки мастера «Назад», «Далее» и «Отправить» — `type="button"`. Внутри `<form>` приложения они
не запускают нативную отправку внешней формы: отправку мастер делает сам, через `onSubmit`.

Снаружи мастера им управляет сам поток: `bundle.flow.next()`, `bundle.flow.goTo('phone')`.
Состояние для своей разметки — `useFormFlow(bundle.flow)` из `@reformer/core/react`.

## Доступность

- Индикатор — `role="navigation"` с подписью «Шаги формы». Каждый шаг в нём — элемент с
  `role="button"`, подписью вида «Шаг 2: Телефон (текущий)» и `aria-current="step"` у текущего.
- Доступные шаги индикатора достижимы по Tab и открываются клавишей Enter или пробелом.
  Недоступные помечены `aria-disabled` и выпадают из порядка Tab.
- Цвета индикатора — из токенов темы. Пройденный шаг отмечен галочкой «✓» и линией цвета
  `primary`, а не только цветом.
- Смену шага объявляет скрытая область `role="status"`: «Шаг 2 из 3».
- Кнопки «Назад», «Далее», «Отправить» — обычные кнопки [Button](./button.mdx). Пока идёт проверка
  или отправка, они выключены, а текст меняется на «Проверка...» и «Отправка...».
- После перехода окно прокручивается к началу (`scrollToTop`), но фокус мастер не переносит.
  Чтобы фокус встал на первое поле шага, переведите его в `onStepChange`.

## Локализация

Мастер рисует свои строки — кнопки, статусы и подписи для скринридера:

| Ключ                        | По-русски                                          | Как заменить в одном мастере            |
| --------------------------- | -------------------------------------------------- | --------------------------------------- |
| `kit.formWizard.prev`       | ← Назад                                            | `prevLabel` у `FormWizardActions`       |
| `kit.formWizard.next`       | Далее →                                            | `nextLabel` у `FormWizardActions`       |
| `kit.formWizard.submit`     | Отправить                                          | `submitLabel` у `FormWizard`            |
| `kit.formWizard.validating` | Проверка...                                        | `validatingLabel` у `FormWizardActions` |
| `kit.formWizard.submitting` | Отправка...                                        | `submittingLabel` у `FormWizardActions` |
| `kit.formWizard.progress`   | Шаг \{current} из \{total} • \{percent}% завершено | `format` у `FormWizardProgress`         |
| `kit.formWizard.stepsNav`   | Шаги формы                                         | `navAriaLabel` у `StepIndicator`        |
| `kit.formWizard.stepLabel`  | Шаг \{number}: \{title} …                          | `stepAriaLabel` у `StepIndicator`       |
| `cdk.formWizard.stepStatus` | объявление смены шага                              | словарь cdk                             |

У самого `FormWizard` из этих пропсов есть только `submitLabel`. Остальные строки меняются
словарём во всём приложении — вторым источником загрузчика локали (см.
[обзор](./overview.md#локализация)) — или сборкой мастера из оформленных частей.
