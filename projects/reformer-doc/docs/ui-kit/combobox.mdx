# Combobox

Выбор из списка с поиском. Кнопка показывает выбранное и открывает всплывающий список, над
которым стоит поле поиска. В семействе четыре компонента: одно значение, несколько значений и те
же два режима для выбора из дерева.

## Когда брать

- **`Combobox`** — опций много (больше 10–15), и человеку проще найти нужную по названию:
  страна, город, валюта.
- **`ComboboxMulti`** — то же, но значений несколько: навыки, теги.
- **`ComboboxTree`** — выбор одного узла иерархии: файл в проекте, раздел каталога.
- **`ComboboxTreeMulti`** — набор узлов иерархии: несколько файлов.
- Нужна возможность ввести своё значение, которого нет в списке, — `creatable`.

Соседи:

- опций немного, поиск не нужен — [Select](./select.mdx): у `SelectAsync` есть и подгрузка опций
  с сервера;
- свободный текст с подсказками, а не выбор из списка — [Input](./input.mdx), компонент
  `InputSuggest`;
- 2–5 опций, которые лучше видеть сразу, — [RadioGroup](./radio-group.mdx) или
  [ToggleGroup](./toggle-group.mdx);
- дерево само по себе, без значения поля, — [Tree](./tree.mdx).

## Анатомия

| Компонент           | Значение поля      | Ключевые пропсы                                                     |
| ------------------- | ------------------ | ------------------------------------------------------------------- |
| `Combobox`          | `string \| null`   | `options`, `placeholder`, `clearable`, `creatable`                  |
| `ComboboxMulti`     | `string[] \| null` | `options`, `clearable`, `creatable`, `maxItems`, `summaryThreshold` |
| `ComboboxTree`      | `string \| null`   | `nodes`, `loadChildren`, `selectable`, `clearable`, `maxRows`       |
| `ComboboxTreeMulti` | `string[] \| null` | `nodes`, `loadChildren`, `selectable`, `maxItems`, `maxRows`        |

**Плоский список.** `Combobox` и `ComboboxMulti` собраны из [Popover](./popover.mdx),
[Command](./command.mdx) и [Button](./button.mdx). Опции — массив `{ value, label }`: поиск идёт
по `label`, в значение поля уходит `value`. У `Combobox` при `clearable` крестик и повторный
выбор той же опции сбрасывают значение в `null`. `ComboboxMulti` показывает выбранное чипами;
когда чипов больше `summaryThreshold` (по умолчанию 3), они сворачиваются в «Выбрано: N». Список
после выбора не закрывается — можно отметить несколько опций подряд.

**Дерево.** `ComboboxTree` и `ComboboxTreeMulti` принимают `nodes` вместо `options`. Значение
поля — `id` узла; для файла удобно делать `id` полным путём. `loadChildren` читает уровни лениво,
при первом раскрытии ветки. По умолчанию `selectable="leaf"`: щелчок по каталогу раскрывает
его, а не выбирает; `selectable="all"` разрешает выбрать и каталог. Список в поповере — [Tree](./tree.mdx)
кита, а не Command: фильтр Command при поиске убирает несовпавшие строки вместе с их детьми,
и иерархия распадается. Поэтому поиск у дерева свой: он оставляет путь до совпадения.

**Пустой выбор у множественных вариантов** приходит как `null`, а не `[]`. Обязательность
выражают правилом `required()`, потолок — `maxLength(n)`. Проп `maxItems` только выключает
лишние опции в интерфейсе, правилом формы он не является.

Компонент тяжёлый. Он не входит в главный вход кита: импорт — из подпути
`@reformer/ui-kit/combobox`, рядом нужна необязательная зависимость `cmdk` (≥ 1).

```tsx
import { Combobox } from '@reformer/ui-kit/combobox';

{
  model: model.$.country,
  component: Combobox,
  componentProps: {
    label: 'Страна',
    options: [
      { value: 'ru', label: 'Россия' },
      { value: 'kz', label: 'Казахстан' },
    ],
    clearable: true,
  },
}
```

Общие пропсы полей (`label`, `required`, `description`, `tooltip` и другие) — в
[описании FormField](./form-field.mdx#общие-пропсы-полей). Combobox уже работает со значением,
а не с событием, поэтому вне формы подключается теми же `value` и `onChange`.

Из поведения формы список можно открыть программно (снаружи — через `bundle.render.node(...)`):
`schema.node('country').getRef<ComboboxHandle>().current?.open()`. Кроме `open()` ссылка на
компонент даёт `close()`, `clear()`, фокус и прокрутку к полю.

## Доступность

- Кнопка — `role="combobox"` с `aria-expanded`. На неё [FormField](./form-field.mdx) вешает
  подпись (`aria-labelledby`), пояснение и замечание (`aria-describedby`, `aria-errormessage`),
  `aria-invalid` и `aria-required`.
- Enter или пробел на кнопке открывают список, фокус переходит в поле поиска. Esc закрывает
  список, закрытие отмечает поле [тронутым](../reference/glossary.md#валидация).
- `Combobox`, `ComboboxMulti`: клавиатуру списка даёт Command (cmdk) — ↑/↓ по опциям, Enter —
  выбрать.
- `ComboboxTree`, `ComboboxTreeMulti`: ↓ из поля поиска переводит фокус в дерево (`role="tree"`).
  Дальше ↑/↓ — по строкам, → — раскрыть ветку, ← — свернуть или подняться к родителю,
  Home/End — к первой и последней строке, Enter — выбрать.
- Крестик очистки доступен только мышью (`tabIndex={-1}`). С клавиатуры одно значение снимают
  повторным выбором той же опции (при `clearable`), множественное — снятием отметок в списке.

## Локализация

Строки, которые рисует сам компонент, берутся из словаря кита. Заменить их для одного поля —
пропом, для всего приложения — ключом словаря.

| Ключ                                                                | Где                                          | Проп                |
| ------------------------------------------------------------------- | -------------------------------------------- | ------------------- |
| `kit.combobox.placeholder`                                          | кнопка без значения (`Combobox`)             | `placeholder`       |
| `kit.combobox.placeholderMulti`                                     | кнопка без значения (`ComboboxMulti`)        | `placeholder`       |
| `kit.combobox.treePlaceholder`, `kit.combobox.treePlaceholderMulti` | кнопка без значения у дерева                 | `placeholder`       |
| `kit.combobox.search`                                               | поле поиска                                  | `searchPlaceholder` |
| `kit.combobox.empty`, `kit.combobox.treeEmpty`                      | «ничего не найдено»                          | `emptyText`         |
| `kit.combobox.create`                                               | пункт создания своего значения (`creatable`) | —                   |
| `kit.combobox.selected`                                             | сводка «Выбрано: N»                          | —                   |
| `kit.combobox.clear`                                                | подпись крестика для скринридера             | —                   |

Как подключить русскую локаль кита — в [обзоре](./overview.md#локализация).
