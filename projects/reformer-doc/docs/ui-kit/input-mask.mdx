# InputMask

<ComponentDoc config={inputMaskDocConfig}>
Текстовое поле, которое показывает шаблон ввода в пустом поле: `+7 (999) 999-99-99`. В шаблоне
`9` — цифра, остальные символы — как есть. В форме `InputMask` кладётся в `component`
[узла схемы](../reference/glossary.md#форма-и-данные) как есть.

:::caution Шаблон — только подсказка
`InputMask` не вставляет скобки и дефисы и не запрещает лишние символы. В модель уходит ровно
то, что набрал человек. Формат проверяет правило в
[схеме валидации](../reference/glossary.md#валидация), например `pattern`.
:::

## Когда брать

- Значение с известным форматом, который полезно показать заранее: телефон, ИНН, СНИЛС, серия и
  номер паспорта, дата `ДД.ММ.ГГГГ`.

Соседи:

- код из ячеек фиксированной длины — [InputOTP](./input-otp.mdx);
- дата с календарём — [DatePicker](./date-picker.mdx);
- свободная строка без формата — [Input](./input.mdx).

Нужно, чтобы поле само расставляло символы шаблона при вводе, — подключите библиотеку масок как
свой компонент поля, см. [Свои компоненты полей](../react/custom-fields.md).

## Анатомия

| Компонент   | Значение поля    | Ключевые пропсы                   |
| ----------- | ---------------- | --------------------------------- |
| `InputMask` | `string \| null` | `mask`, `placeholder`, `readOnly` |

- `mask` — шаблон. Показывается в пустом поле, пока не задан `placeholder`.
- `placeholder` — своя подсказка вместо шаблона: `'ДД.ММ.ГГГГ'` для маски `99.99.9999`.
- Пустой ввод даёт `null`.

Частые шаблоны:

| Поле                   | `mask`                        |
| ---------------------- | ----------------------------- |
| Телефон                | `+7 (999) 999-99-99`          |
| ИНН физлица / юрлица   | `999999999999` / `9999999999` |
| СНИЛС                  | `999-999-999 99`              |
| Серия и номер паспорта | `9999 999999`                 |
| Дата                   | `99.99.9999`                  |

Правило формата пишите под то, что реально придёт в модель. Если человеку разрешено набрать
телефон без скобок, регулярное выражение со скобками его не пропустит: либо требуйте формат
шаблона и сообщайте об этом в замечании, либо приводите значение к нему сами.

Кроме своих пропсов, поле понимает общие для всех полей кита: `label`, `required`, `description`,
`labelTooltip`, `tooltip`, `testId` — см. [FormField](./form-field.mdx#общие-пропсы-полей).

```tsx
{
  model: model.$.phone,
  component: InputMask,
  componentProps: { label: 'Телефон', mask: '+7 (999) 999-99-99' },
}

// правила — в схеме валидации:
validate(model.$.phone, [required(), pattern(/^\+7 \(\d{3}\) \d{3}-\d{2}-\d{2}$/)]);
```

`value`, `onChange`, `onBlur` и `disabled` в `componentProps` не пишут: их подставляет обёртка
поля. Вне формы `InputMask` тоже работает со значением, а не с событием: `onChange` получает
строку или `null`.

## Доступность

- Под капотом настоящий `<input type="text">`: фокус по Tab, ввод и вставка работают как обычно.
- Шаблон выводится как `placeholder`: он исчезает при вводе и подпись не заменяет. Формат стоит
  повторить в `description` — пояснение привязано к полю, и скринридер прочтёт его вместе с
  подписью.
- `FormField` связывает поле с подписью (`<label for>`, `aria-labelledby`), пояснением и
  замечанием (`aria-describedby`). Пока замечание показано, у поля стоят `aria-invalid` и
  `aria-errormessage`; при `required` — `aria-required`.

## Локализация

Своих строк `InputMask` не рисует: шаблон и `placeholder` задаёте вы. Встроенная строка одна —
подпись кнопки-иконки `tooltip` для скринридера, ключ `kit.infoHint.label` («Подсказка»). Тексты
замечаний берутся из [словаря сообщений](../reference/glossary.md#валидация) формы. Как подключить
русскую локаль кита — в [обзоре](./overview.md#локализация).
