# Textarea

Многострочное текстовое поле на pure shadcn `Textarea`. Значение — `string | null`
(пустой ввод → `null`). В форме `Textarea` кладётся в `component` как есть: DOM-событие
в значение поля переводит обёртка поля по статике `nativeInputAdapter`.
