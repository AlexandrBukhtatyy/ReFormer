# Slider

Ползунок для выбора числа из диапазона. Значение поля — `number | null`, границы и шаг задают
`min`, `max` и `step`. В `component` [узла схемы](../reference/glossary.md#форма-и-данные)
`Slider` кладётся как есть.

## Когда брать

- Число, которое удобнее «прикинуть», чем набрать: громкость, оценка, процент скидки.
- Шкала короткая или шаг крупный, и точное значение не критично.

Соседи:

- точное число, особенно большое (сумма, срок) — [Input](./input.mdx), компонент `InputNumber`;
- выбор из нескольких фиксированных значений — [RadioGroup](./radio-group.mdx) или
  [ToggleGroup](./toggle-group.mdx).

## Анатомия

| Компонент | Значение поля    | Ключевые пропсы      |
| --------- | ---------------- | -------------------- |
| `Slider`  | `number \| null` | `min`, `max`, `step` |

Внутри — Radix Slider: дорожка (`Track`), заполненная часть (`Range`) и ручка (`Thumb`). В форме
ручка одна: значение — одно число. По умолчанию шкала `0…100` с шагом `1`. Значение вне
`min…max` слайдер прижимает к ближайшей границе; у пустого поля (`null`) при `min ≥ 0` ручка
стоит на `min`. Текущее число слайдер не подписывает — если оно важно, выводите его рядом или
берите `InputNumber`.

```tsx
{
  model: model.$.rating,
  component: Slider,
  componentProps: { label: 'Оценка', min: 0, max: 10, step: 2 },
}
```

Подпись над слайдером рисует [FormField](./form-field.mdx), как у текстовых полей. Общие пропсы
полей (`label`, `required`, `description`, `tooltip` и другие) —
в [описании FormField](./form-field.mdx#общие-пропсы-полей).

Вне формы `Slider` — обычный Radix Slider: значение массивом, `value={[n]}` и
`onValueChange={([n]) => …}`.

## Доступность

- Ручка — элемент с `role="slider"` и `aria-valuemin`, `aria-valuemax`, `aria-valuenow`; её
  ставит Radix.
- Клавиатура (Radix): ←/↓ и →/↑ — на один шаг, Shift + стрелка и PageUp/PageDown — на десять
  шагов, Home/End — к минимуму и максимуму.
- Уход фокуса с ручки отмечает поле [тронутым](../reference/glossary.md#валидация).
- `id` и связи от `FormField` (`aria-labelledby`, `aria-describedby`, `aria-invalid`,
  `aria-errormessage`) слайдер ставит на ручку с `role="slider"`: скринридер называет её по подписи
  поля, а щелчок по подписи переводит фокус на ручку. При показанной ошибке ручка обведена цветом
  ошибки.
- `aria-required` у роли `slider` не предусмотрен, и слайдер его не ставит.

## Локализация

Слайдер текста не рисует. Встроенная строка одна — подпись кнопки-иконки `tooltip` для
скринридера, ключ `kit.infoHint.label`. Как подключить русскую локаль кита — в
[обзоре](./overview.md#локализация).
