# Kbd

<ComponentDoc config={kbdDocConfig}>
Показывает клавишу или сочетание клавиш: «нажмите Ctrl K». `Kbd` — одна клавиша, `KbdGroup` —
несколько клавиш в ряд. Оба рисуют HTML-элемент `<kbd>`, который и означает «ввод с клавиатуры».

## Когда брать

- **Kbd** — подсказка о горячей клавише в тексте, в [Tooltip](./tooltip.mdx), в пункте
  [DropdownMenu](./dropdown-menu.mdx) или [Command](./command.mdx).
- [Badge](./badge.mdx) — метка статуса или категории, а не клавиша.
- [Typography](./typography.mdx) — фрагмент кода или имя файла в тексте.

## Анатомия

```tsx
import { Kbd, KbdGroup } from '@reformer/ui-kit'; // или '@reformer/ui-kit/kbd'

<p>
  Нажмите{' '}
  <KbdGroup>
    <Kbd>Ctrl</Kbd>
    <Kbd>K</Kbd>
  </KbdGroup>{' '}
  для поиска.
</p>;
```

| Часть      | Что это                                                            | Ключевые пропсы         |
| ---------- | ------------------------------------------------------------------ | ----------------------- |
| `Kbd`      | Одна клавиша: элемент `<kbd>` высотой 20px с серым фоном.          | `children`, `className` |
| `KbdGroup` | Сочетание: элемент `<kbd>` со строчным рядом клавиш и зазором 4px. | `children`, `className` |

- Оба строчные (`inline-flex`) — их ставят прямо в предложение.
- Знак «+» или слово «затем» между клавишами — обычный текст внутри `KbdGroup`, а не отдельный
  `Kbd`.
- Внутри `TooltipContent` клавиша сама меняет цвета под тёмный фон подсказки.
- Иконка `svg` внутри `Kbd` получает размер 12px, если вы не задали свой класс `size-*`.

## Доступность

- `<kbd>` — семантика «клавиша». Скринридер читает его как обычный текст.
- Символы `⌘`, `⌥`, `↵` скринридер может прочитать неразборчиво или пропустить. Пишите название
  клавиши словом (`Enter`, `Cmd`) или добавляйте пояснение рядом.
- Kbd не реагирует на мышь и не выделяется при выделении текста (`pointer-events-none`,
  `select-none`). Это подпись, а не кнопка: не вешайте на него обработчики щелчка.
- Сочетание должно реально работать там, где о нём пишут: обработчик клавиш — ваш код.

## Локализация

Своих строк компонент не рисует. Названия клавиш — ваш текст: на macOS привычнее `⌘` и `⌥`, на
Windows — `Ctrl` и `Alt`.
