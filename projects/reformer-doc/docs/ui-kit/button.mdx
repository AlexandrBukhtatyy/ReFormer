# Button

<ComponentDoc config={buttonDocConfig}>
Кнопка запускает действие: отправить форму, открыть окно, удалить запись. Вид задаёт `variant`,
размер — `size`. Компонент входит в [кит](../reference/glossary.md#пакеты) `@reformer/ui-kit`,
это не поле формы.

## Когда брать

- **Button** — действие на странице или в форме.
- **Button с `asChild`** — переход по адресу, который должен выглядеть как кнопка. Внутрь кладут
  `<a>` или `Link` роутера: для скринридера это остаётся ссылкой.
- [Toggle](./toggle.mdx) — кнопка с состоянием «нажата / отжата» (жирный шрифт, фильтр). Она
  сообщает состояние через `aria-pressed`, обычная кнопка — нет.
- [ButtonGroup](./button-group.mdx) — несколько связанных кнопок в один ряд.
- [DropdownMenu](./dropdown-menu.mdx) — список действий за одной кнопкой; `Button` служит его
  триггером.
- Кнопки «Назад», «Далее», «Отправить» многошаговой формы рисует
  [FormWizard](./form-navigation.mdx) — свои делать не нужно.

## Анатомия

```tsx
import { Button } from '@reformer/ui-kit'; // или '@reformer/ui-kit/button'

<Button variant="outline" size="sm" type="button" onClick={onCancel}>
  Отмена
</Button>;
```

Это один элемент `<button>`. Все атрибуты нативной кнопки (`type`, `onClick`, `disabled`,
`aria-*`) передаются как есть.

| Проп      | Значения                                                             | По умолчанию | Что делает                                                  |
| --------- | -------------------------------------------------------------------- | ------------ | ----------------------------------------------------------- |
| `variant` | `default`, `secondary`, `outline`, `ghost`, `destructive`, `link`    | `default`    | Вид кнопки.                                                 |
| `size`    | `xs`, `sm`, `default`, `lg`, `icon-xs`, `icon-sm`, `icon`, `icon-lg` | `default`    | Размер; `icon-*` — квадрат под одну иконку.                 |
| `asChild` | `boolean`                                                            | `false`      | Отрисовать вместо `<button>` единственный дочерний элемент. |

Какой вид для какого действия:

| `variant`     | Для чего                                                            |
| ------------- | ------------------------------------------------------------------- |
| `default`     | Главное действие экрана: «Сохранить», «Отправить».                  |
| `secondary`   | Второстепенное действие рядом с главным.                            |
| `outline`     | «Отмена», «Изменить», триггер меню или окна.                        |
| `ghost`       | Кнопки в тулбаре, в строке таблицы, в меню — без фона до наведения. |
| `destructive` | Необратимое действие: «Удалить», «Отозвать».                        |
| `link`        | Действие, которое выглядит как ссылка в тексте.                     |

Цвет меняйте вариантом, а не классами `bg-*`: варианты берут цвета из темы и верны в тёмной теме.

## Доступность

Компонент рисует нативный `<button>`, поэтому клавиатуру даёт браузер:

| Клавиша           | Действие                              |
| ----------------- | ------------------------------------- |
| `Tab`             | Фокус на кнопку и дальше по странице. |
| `Enter` / `Space` | Нажать кнопку.                        |

- Фокус обозначен кольцом (`focus-visible:ring`).
- `disabled` убирает кнопку из порядка `Tab`, и скринридер объявляет её недоступной.
- Кнопке без текста (`size="icon*"`) обязательно нужен `aria-label` — иначе у неё нет имени.
- У нативной кнопки тип по умолчанию — `submit`. Внутри `<form>` всем кнопкам, которые не
  отправляют форму, ставьте `type="button"`, иначе щелчок отправит форму.
- С `asChild` роль даёт дочерний элемент. У ссылки нет `disabled`: недоступный переход рисуйте
  обычной кнопкой с `disabled`.
- `aria-invalid` на кнопке подсвечивает её цветом ошибки — стили для этого в компоненте есть.

## Локализация

Своих строк компонент не рисует: подпись — `children`, имя кнопки-иконки — ваш `aria-label`.
