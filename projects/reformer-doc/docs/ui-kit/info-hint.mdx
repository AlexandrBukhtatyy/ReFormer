# InfoHint

<ComponentDoc config={infoHintDocConfig}>
Иконка (i) с подсказкой. Подсказка открывается наведением курсора, фокусом с клавиатуры и
касанием на телефоне. Компонент построен на [Tooltip](./tooltip.mdx), но приносит свой провайдер и
работает в любом месте без обёрток. Входит в [кит](../reference/glossary.md#пакеты)
`@reformer/ui-kit`, это не поле формы.

## Когда брать

- **InfoHint** — пояснение к заголовку, карточке или своему контролу: «Как в документе, без
  сокращений».
- В полях кита InfoHint вручную не нужен. Иконку внутри поля даёт проп `tooltip`, иконку после
  подписи — `labelTooltip`, который разбирает [FormField](./form-field.mdx). В
  [схеме формы](../reference/glossary.md#форма-и-данные) оба пишут в `componentProps`.
- [Tooltip](./tooltip.mdx) — подсказка к кнопке-иконке, у которой уже есть своё действие.
- [Popover](./popover.mdx) — пояснение длиннее пары строк или со ссылками.

## Анатомия

```tsx
import { InfoHint } from '@reformer/ui-kit'; // или '@reformer/ui-kit/info-hint'

<h3 className="flex items-center gap-1.5">
  Паспортные данные <InfoHint content="Как в документе, без сокращений" />
</h3>;
```

Это кнопка-иконка размером 16px (зона касания — 24px) с подсказкой.

| Проп            | Тип                                      | По умолчанию | Что делает                                           |
| --------------- | ---------------------------------------- | ------------ | ---------------------------------------------------- |
| `content`       | `string`                                 | —            | Текст подсказки. Пустая строка — ничего не рисуется. |
| `side`          | `'top' \| 'right' \| 'bottom' \| 'left'` | `top`        | Сторона появления.                                   |
| `delayDuration` | `number`                                 | `150`        | Пауза перед показом по наведению, мс.                |
| `descriptionId` | `string`                                 | —            | id скрытой копии текста для `aria-describedby` поля. |
| `aria-label`    | `string`                                 | «Подсказка»  | Имя кнопки для скринридера.                          |
| `className`     | `string`                                 | —            | Обычно положение иконки поверх поля.                 |

- Кнопка всегда `type="button"`: внутри формы она её не отправит.
- Кнопка никогда не бывает недоступной (`disabled`) — подсказку можно прочитать и у выключенного
  поля.
- Свой контрол получает проп `tooltip` декоратором `withFieldTooltip` из `@reformer/ui-kit/fields`;
  композит, который сам ставит иконку, — хуком `useFieldTooltip`.

## Доступность

| Клавиша           | Действие                              |
| ----------------- | ------------------------------------- |
| `Tab`             | Фокус на иконку показывает подсказку. |
| `Enter` / `Space` | Открыть или закрыть подсказку.        |
| `Esc`             | Закрыть подсказку.                    |

- Иконка — настоящая кнопка с именем «Подсказка» (или вашим `aria-label`); сама картинка скрыта от
  скринридера.
- Открытая подсказка связана с кнопкой через `aria-describedby`, как у [Tooltip](./tooltip.mdx#доступность).
- Закрытая подсказка в разметке отсутствует, поэтому сослаться на неё из поля нельзя. Чтобы
  скринридер читал пояснение при фокусе на самом поле, передайте `descriptionId` и тот же id в
  `aria-describedby` поля (пример «Описание для поля»): InfoHint нарисует скрытую копию текста.
- Касание открывает подсказку, повторное касание или касание мимо — закрывает.

## Локализация

Кит рисует сам одну строку — имя кнопки для скринридера:

| Ключ словаря         | English | Русский   |
| -------------------- | ------- | --------- |
| `kit.infoHint.label` | Hint    | Подсказка |

Для одной иконки имя задаёт проп `aria-label` (лучше конкретное: «Подсказка: паспортные данные»).
Для всего приложения язык берётся из `I18nProvider` (`@reformer/core/react`) с локалью кита
`loadKitLocale` из `@reformer/ui-kit/locale`; без провайдера имя английское. Свою формулировку
задаёт источник словаря после `loadKitLocale`:

```tsx
import { createLocaleLoader } from '@reformer/core/i18n';
import { loadKitLocale } from '@reformer/ui-kit/locale';

const loadLocale = createLocaleLoader([
  loadKitLocale,
  (code) => (code === 'ru' ? { 'kit.infoHint.label': 'Пояснение' } : null),
]);
```
