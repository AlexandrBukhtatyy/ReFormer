# HoverCard

<ComponentDoc config={hoverCardDocConfig}>
Карточка-превью, которая появляется, когда курсор задерживается на ссылке или ссылка получает
фокус: профиль автора, сведения о документе. Построена на Radix HoverCard и входит в
[кит](../reference/glossary.md#пакеты) `@reformer/ui-kit`, это не поле формы.

## Когда брать

- **HoverCard** — дополнительные сведения о том, на что указывает ссылка, чтобы не переходить по
  ней: кто это, что за документ. Без них можно обойтись.
- [Tooltip](./tooltip.mdx) — одна строка пояснения к кнопке или иконке.
- [Popover](./popover.mdx) — панель с кнопками или полями; открывается щелчком.
- [InfoHint](./info-hint.mdx) — пояснение к полю или заголовку, которое должно открываться и
  касанием на телефоне.

На телефоне наведения нет, и карточку там не увидят. Не кладите в неё то, без чего нельзя
работать, и кнопки действий.

## Анатомия

```tsx
import { HoverCard, HoverCardTrigger, HoverCardContent } from '@reformer/ui-kit'; // или '@reformer/ui-kit/hover-card'

<HoverCard openDelay={300}>
  <HoverCardTrigger href="/users/anna">@anna</HoverCardTrigger>
  <HoverCardContent>Анна Смирнова · аналитик, в команде с 2023 года</HoverCardContent>
</HoverCard>;
```

| Часть              | Что это                                                                   | Ключевые пропсы                                                    |
| ------------------ | ------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| `HoverCard`        | Корень: задержки и открытость.                                            | `openDelay` (`700`), `closeDelay` (`300`), `open` + `onOpenChange` |
| `HoverCardTrigger` | Ссылка, при наведении на которую появляется карточка. По умолчанию `<a>`. | `href`, `asChild`                                                  |
| `HoverCardContent` | Карточка в портале, ширина `w-64`.                                        | `side` (`bottom`), `align` (`center`), `sideOffset` (`4`)          |

- Карточка не исчезает, пока курсор переходит с триггера на неё: по ссылкам внутри неё можно
  щёлкнуть.
- Задержки защищают от мигания при случайном проезде курсора; слишком короткая `openDelay`
  мешает читать страницу.
- Если не хватает места, карточка сама переезжает на другую сторону.

## Доступность

| Клавиша | Действие                                                      |
| ------- | ------------------------------------------------------------- |
| `Tab`   | Фокус на триггер открывает карточку, уход фокуса — закрывает. |
| `Esc`   | Закрыть карточку.                                             |

- Radix делает карточку для зрячих пользователей: скринридер её содержимое не объявляет, а фокус в
  карточку не переходит. Поэтому всё важное должно быть доступно и без неё — по самой ссылке.
- Триггер — ссылка; на странице, куда она ведёт, человек найдёт те же сведения.
- На сенсорных экранах карточка не открывается.

## Локализация

Своих строк компонент не рисует: текст карточки — ваш.
