# Интерфейс

Окно билдера устроено как у редактора кода: в центре — открытый документ, по краям — панели,
внизу — строка состояния. Какие панели есть, решают плагины: открыли форму ReFormer —
появились «Компоненты» и «Свойства», открыли markdown — их нет.

## Панели

Панели открываются кнопками на **рейлах** — узких колонках значков у левого и правого края.
Повторный щелчок по кнопке прячет панель. Ширину панели меняет перетаскивание её границы.

| Панель            | Где    | Что в ней                                                                              |
| ----------------- | ------ | -------------------------------------------------------------------------------------- |
| **Проект**        | слева  | дерево файлов открытой папки и действия над ними                                       |
| **Компоненты**    | слева  | палитра компонентов активного кита; есть, пока открыта форма ReFormer                  |
| **Шаблоны форм**  | слева  | встроенные и свои шаблоны, создание формы по шаблону                                   |
| **Свойства**      | справа | свойства выбранного узла формы (ReFormer) или поля (RJSF)                              |
| **Экспорт формы** | справа | генерация модуля формы — см. [Экспорт кода](./codegen-and-templates.md)                |
| **Ассистент**     | справа | разговор с ИИ-ассистентом — см. [ИИ-ассистент](./assistant.md)                         |
| **MCP-серверы**   | справа | внешние инструменты ассистента из проекта                                              |
| **Превью**        | справа | приложение целиком; только когда билдер [встроен в приложение](./embedding.mdx)        |
| **Журнал**        | снизу  | вид «Проблемы» — находки проверок в открытых документах; вид «События» — сбои и отказы |
| **Модель**        | снизу  | значения живой формы и состояние её полей; есть, пока открыта форма ReFormer           |

`Ctrl+B` прячет и показывает левую панель, `Ctrl+J` — нижнюю.

### Дерево проекта

Одиночный щелчок по файлу открывает его **временной вкладкой** — следующий одиночный щелчок
заменит её на месте. Двойной щелчок открывает вкладку насовсем.

Контекстное меню строки: «Новый файл…», «Новая папка…», «Переименовать…» (`F2`), «Удалить»
(`Delete`), «Копировать», «Вырезать», «Вставить», «Копировать путь», «Открыть рядом»,
«Прикрепить к ассистенту». Плагины добавляют свои пункты — например, «Сгенерировать» у формы и
«Шаблоны» у каталога. Число ошибок и предупреждений проверок показывается прямо на строке файла.

## Вкладки и виды

Каждый открытый файл — вкладка. Точка на вкладке значит несохранённые правки; закрыть такую
вкладку билдер даст, только спросив: «Сохранить и закрыть» или «Закрыть без сохранения».

Справа на полосе вкладок — кнопки **видов** документа. У формы ReFormer их четыре: «Дерево»,
«Схема», «Форма» и «Исходный код»; у формы RJSF — «Структура», «Форма» и «Исходник». Кнопка
«Ещё действия» (`…`) собирает остальное, например «Открыть другим редактором». Чем один вид
отличается от другого — на странице [Редактирование формы](./editing.md).

## Строка состояния

| Ячейка                                    | Что значит                                                                                   |
| ----------------------------------------- | -------------------------------------------------------------------------------------------- |
| «Всё сохранено» / «3 несохранённых файла» | есть ли правки, которые ещё не записаны на диск                                              |
| «2 файла изменены снаружи»                | файлы поменяли мимо билдера, например в IDE; при сохранении билдер спросит, чья версия верна |
| «Язык: RU»                                | язык интерфейса                                                                              |
| «Конструктор»                             | профиль состава — какие встроенные плагины собраны; см. [Конфигурация](./configuration.md)   |
| «ReFormer UI Kit»                         | активный кит; щелчок — список китов, если их больше одного                                   |

## Палитра команд

`Ctrl+Shift+P` открывает палитру: поиск по всем командам билдера и плагинов и по файлам
проекта. Подходит, когда не помните, где кнопка: «Кит: …», «Плагины: перезагрузить …»,
«Ассистент: новый разговор».

![Палитра команд со списком команд](/img/builder/command-palette.png)

Команды, которые есть в палитре, ассистент вызывает теми же командами — отдельного «набора для
ИИ» у билдера нет.

## Меню

- **«Файл»** — «Открыть папку…», «Недавно открытые», «Сохранить», «Сохранить всё», «Очистить
  кэш», «Настройки».
- **«Справка»** — «Горячие клавиши», «О программе».

**«Очистить кэш»** удаляет то, что билдер хранит в браузере: рабочие копии, кэш сборки,
настройки, список вкладок и выбранные плагины. Несохранённые правки пропадут, файлы на диске
не изменятся.

## Настройки

`Ctrl+,` или «Файл» → «Настройки». Разделы:

- **«Внешний вид»** — тема: светлая, тёмная или как в системе.
- **«Язык»** — русский или English, меняется без перезагрузки.
- **«Плагины»** — список плагинов, их включение и настройки; подробнее — в
  [Плагины: понятия](./plugins/concepts.md).

Значение, заданное настройками проекта (`.ui_builder/settings.json`), перекрывает глобальное, и
окно настроек об этом говорит.

## Горячие клавиши

На macOS вместо `Ctrl` — `Cmd`.

| Клавиши            | Действие                    |
| ------------------ | --------------------------- |
| `Ctrl+Shift+P`     | палитра команд              |
| `Ctrl+S`           | сохранить активный документ |
| `Ctrl+Alt+S`       | сохранить всё               |
| `Ctrl+R`           | недавно открытые проекты    |
| `Ctrl+B`           | левая панель                |
| `Ctrl+J`           | нижняя панель               |
| `Ctrl+,`           | настройки                   |
| `Ctrl+K`, `Ctrl+S` | список горячих клавиш       |

Клавиши редактора формы — на странице [Редактирование формы](./editing.md#клавиши-редактора).
Любое сочетание переназначается в окне «Горячие клавиши»: «Изменить», затем новое сочетание.
Аккорд — два нажатия подряд.

## Уведомления и журнал

Уведомление в углу живёт несколько секунд. Если что-то сломалось — плагин не загрузился,
команда отказала, — уведомление отсылает в журнал: «Подробности — в журнале». Запись журнала
остаётся до перезагрузки страницы, подробности ошибки раскрываются кнопкой «Подробности».
