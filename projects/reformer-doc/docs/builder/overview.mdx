# Билдер ReFormer

**ReFormer Builder** — визуальный конструктор форм. В нём форму собирают из компонентов, сразу
видят живой, правят свойства полей и выгружают кодом — готовым модулем, который подключается
к приложению на React.

<Link className="button button--primary button--lg" to="pathname:///builder/">
  Открыть билдер ↗
</Link>

![Билдер с открытой формой: слева дерево проекта, в центре дерево узлов формы, справа свойства выбранного поля](/img/builder/shell.png)

## Когда он нужен

- **Собрать форму быстрее, чем писать схему руками.** Поля берутся из палитры кита, раскладка
  меняется перетаскиванием, подписи и привязки к модели правятся в панели свойств.
- **Поправить готовую форму.** Билдер открывает тот же JSON-документ формы, что лежит в
  репозитории, и пишет правки обратно в файл.
- **Поручить черновик ИИ.** Ассистент добавляет поля, правила и шаги по просьбе обычным
  текстом. Модель подключается своя: облачная по ключу API или локальная, например Ollama.
- **Посмотреть форму в настоящем приложении.** Встроенный в приложение билдер показывает форму
  так, как её рисует само приложение, — со своими данными и провайдерами.

## Как он устроен

Серверной части у билдера нет. Он работает в браузере и открывает папку проекта на диске через
File System Access API — поэтому нужен браузер на Chromium: Chrome, Edge, Arc или Brave. Правки
копятся в **рабочей копии** в браузере и записываются в файлы по `Ctrl+S`.

Сам билдер — **оболочка**: открывает проект, сохраняет файлы и управляет плагинами. Всё
остальное приносят **плагины**: дерево файлов, редактор кода, редактор формы, превью, проверки,
генерацию кода, шаблоны, ассистента. Опубликованный билдер везёт их с собой, а проект может
добавить свои — подробнее в разделе [Плагины: понятия](./plugins/concepts.md).

## Три способа запустить

| Способ                   | Как                                                             | Когда выбирать                                                       |
| ------------------------ | --------------------------------------------------------------- | -------------------------------------------------------------------- |
| Онлайн                   | кнопка «Открыть билдер» выше                                    | попробовать или работать с формами без установки                     |
| Локально                 | `npx @reformer/builder@beta`                                    | свой конфиг запуска, свой набор плагинов, работа без доступа к сайту |
| Внутри своего приложения | плагин Vite `reformerBuilder()` и компонент `<ReformerBuilder>` | форму в превью должно рисовать ваше приложение                       |

Подробности — на страницах [Быстрый старт](./quick-start.mdx) и
[Встраивание в Vite-приложение](./embedding.mdx).

## Слова этого раздела

| Термин             | Что это                                                                                                       |
| ------------------ | ------------------------------------------------------------------------------------------------------------- |
| **Оболочка**       | Сам билдер без плагинов: окно, открытие проекта, сохранение, управление плагинами.                            |
| **Плагин**         | Пакет с `manifest.json` и кодом, который добавляет билдеру панели, команды, редакторы.                        |
| **Рабочая копия**  | Файлы проекта, какими их видит билдер, вместе с несохранёнными правками. На диск попадает по `Ctrl+S`.        |
| **Документ формы** | JSON-файл формы, который открывает редактор: `form.schema.json` для ReFormer, `*.rjsf.json` для RJSF.         |
| **Модуль формы**   | Каталог с кодом формы для приложения: схема, модель, правила, поведение, страница. Его печатает экспорт кода. |
| **Кит**            | Набор компонентов полей, которыми рисуется форма. Подробнее — в [глоссарии](../reference/glossary.md#пакеты). |
| **Движок формы**   | Плагины одного формата формы: редактор, превью, проверки, генерация кода. В билдере их два — ReFormer и RJSF. |
| **Ход ассистента** | Ответ ассистента на одну просьбу вместе со всеми правками, которые он сделал. Отменяется целиком.             |

## Ограничения

- **Только Chromium.** File System Access есть только в браузерах на Chromium.
- **Встраивание — только Vite в режиме разработки.** В прод-сборку приложения билдер не попадает.
- **Облачные модели вызываются прямо из браузера.** Ключ API доступен странице — берите ключ
  с ограниченным бюджетом.
