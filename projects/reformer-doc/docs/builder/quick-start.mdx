# Быстрый старт

За десять минут: открыть папку проекта, создать форму по шаблону, поправить её, сохранить на
диск и получить код модуля для приложения.

**Что нужно:** браузер на Chromium (Chrome, Edge, Arc, Brave) и папка на диске — подойдёт пустая
или папка вашего приложения. Устанавливать ничего не нужно.

<Link className="button button--primary button--lg" to="pathname:///builder/">
  Открыть билдер ↗
</Link>

## 1. Откройте папку проекта

На стартовой странице нажмите «Открыть папку…» и выберите папку. Браузер спросит разрешение
читать и изменять файлы в ней — разрешите. При следующем запуске билдер откроет проект снова;
если браузер забыл разрешение, нажмите «Разрешить доступ» в уведомлении. Прошлые папки
хранит список «Недавно открытые».

![Стартовая страница билдера с кнопкой «Открыть папку…»](/img/builder/welcome.png)

Каталог `.ui_builder/` в папке не обязателен. Пока его нет, настройки проекта хранятся в
браузере, а сам билдер в папке ничего не создаёт. Что можно положить в этот каталог — на странице
[Конфигурация `.ui_builder/`](./configuration.md).

## 2. Создайте форму по шаблону

На левом рейле откройте «Шаблоны форм» и выберите «Простая форма». В окне «Создать форму по
шаблону» задайте «Имя формы», например `feedback`, и «Каталог формы» — папку, внутри которой
появится каталог новой формы. Нажмите «Создать форму».

![Окно «Создать форму по шаблону»: имя формы feedback, каталог — корень проекта](/img/builder/template-dialog.png)

Билдер создаст каталог формы — её модуль: документ формы `schema/form.schema.json`, модель,
правила валидации, поведение и страницу. Документ откроется во вкладке.

- «Простая форма» — анкета из трёх секций с полем каждого вида, который есть в ките, правилами
  валидации, вычисляемым полем и условной видимостью.
- «Пошаговая форма» — та же анкета в три шага; есть у кита с компонентом-мастером.

Готовый документ формы из репозитория открывается так же, как любой файл, — двойным щелчком
в дереве «Проект».

## 3. Поправьте форму

![Форма, созданная по шаблону, в виде «Дерево»](/img/builder/template-created.png)

- **Выберите узел** в дереве — его свойства покажет панель «Свойства» на правом рейле: подпись,
  подсказка, обязательность, привязка к модели.
- **Добавьте поле** из панели «Компоненты» на левом рейле — щелчок добавляет компонент в
  выделенный контейнер. Или нажмите `Enter` на узле — откроется быстрый поиск компонента.
- **Переставьте** поля в виде «Схема» перетаскиванием или клавишами `Ctrl+↑` / `Ctrl+↓` на
  выделенном узле.
- **Посмотрите результат** в виде «Форма» — форма живая, в неё можно вводить значения.

Отмена — `Ctrl+Z`, повтор — `Ctrl+Shift+Z`. Подробнее — [Редактирование формы](./editing.md).

## 4. Сохраните

Правки сначала живут в рабочей копии в браузере — строка состояния показывает, сколько файлов
не сохранено. `Ctrl+S` записывает активный документ на диск, `Ctrl+Alt+S` — все. После записи
в строке состояния — «Всё сохранено».

## 5. Обновите код модуля

Код модуля печатается из документа формы. После правок откройте «Экспорт формы» на правом
рейле и нажмите «Сгенерировать»: файлы, которые выводятся из документа, перепечатаются, а файлы с
вашими правками останутся как есть. Обычно панель сразу пишет файлы на диск — под итогом стоит
«Отправлено в источник». Если там «Осталось в рабочей копии — сохраните проект», нажмите
`Ctrl+Alt+S`.

![Панель «Экспорт формы»: имя формы и список файлов модуля](/img/builder/codegen.png)

Какие файлы перезаписываются, а какие ваши, — на странице
[Экспорт кода и шаблоны](./codegen-and-templates.md).

## 6. Подключите форму к приложению

Каталог формы — обычный код на TypeScript и React. Если открыта папка вашего приложения, модуль
уже лежит в его исходниках; иначе скопируйте каталог формы в приложение.

Модуль импортирует пакеты ReFormer — `@reformer/core`, `@reformer/cdk`, `@reformer/renderer-react`,
`@reformer/renderer-json`, `@reformer/form-registry` — и пакет кита, например `@reformer/ui-kit`.
Они нужны приложению зависимостями; как поставить ReFormer и подключить стили кита — на страницах
[Установка](../getting-started/installation.md) и [UI Kit](../ui-kit/overview.md#подключение-стилей).

Страница формы — экспорт по умолчанию из `index.ts` модуля:

```tsx
import FeedbackForm from './forms/feedback';

export function App() {
  return <FeedbackForm />;
}
```

Точная строка подключения для вашей формы — в блоке «Регистрация в приложении» панели «Экспорт
формы» и в `README.md` модуля: там же второй способ — через реестр форм `@reformer/form-registry`.
