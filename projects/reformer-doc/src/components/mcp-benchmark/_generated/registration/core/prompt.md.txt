Сделай форму регистрации:

- логин (`login`) — обязателен, от 3 до 20 символов, только латиница, цифры и `_`;
- email (`email`) — обязателен, проверяется формат;
- пароль (`password`) — обязателен, минимум 8 символов, ввод скрыт;
- повтор пароля (`confirmPassword`) — обязателен и должен совпадать с паролем;
- капча (`captcha`) — поле для кода из 6 символов с картинки, обязательна. Сервера капчи пока нет:
  проверяй асинхронно заглушкой — верный код `ABC123` без учёта регистра, ответ через 300 мс,
  неверный код — ошибка «Символы не совпадают». Картинку пока не рисуй;
- внизу кнопка «Зарегистрироваться».

## Как сдать результат

Положи модуль формы в каталог `form/` текущего рабочего каталога. Точка входа — `form/index.tsx`:
она экспортирует React-компонент формы (именованный `…Form` или default). Форма должна рисоваться
этим компонентом без внешних пропсов.

Стек: `@reformer/core`, разметку пишешь сам в JSX. Пакеты `@reformer/*`, `react` уже установлены, ничего не устанавливай и не
запускай. Когда модуль готов, закончи работу коротким сообщением.


## Раскладка модуля

Проверка собирает форму так же, как `createForm` из `@reformer/core`, — из частей модуля в `form/`:

- `model.ts` — `export function createFormModel()`: модель формы;
- `form.schema.ts` — `export const formSchema` (на `@reformer/renderer-json` — документ
  `form.schema.json`);
- `form.validation.ts` — `export const formValidation`, если у формы есть правила;
- `form.behavior.ts` — `export const formBehavior`, если у формы есть поведение;
- `form.flow.ts` — `export const formFlow`, если форма — мастер с шагами.

`index.tsx` собирает форму из этих частей и экспортирует её компонент.
