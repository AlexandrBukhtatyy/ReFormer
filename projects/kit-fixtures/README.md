# kit-fixtures

Формы для тестов китов ReFormer — пакетов, которые связывают имена каталога компонентов с
компонентами библиотеки (`@reformer/kit-vuetify`, `@reformer/kit-taiga`). Пакет приватный и без
сборки: киты подключают его как `devDependency` и берут формы из исходников.

| Форма          | Что проверяет                                                         |
| -------------- | --------------------------------------------------------------------- |
| `registration` | текстовые поля, пароль, маска, флажок, сообщения об ошибках           |
| `loan`         | визард из двух шагов, массив строк                                    |
| `credit`       | визард, списки, радиокнопки, массивы, условные поля, источники данных |

Документы называют компоненты именами каталога `@reformer/ui-kit` (`Input`, `InputMask`,
`Select`, `FieldArray`, `FormWizard`, `Step`, …). Кит, чей каталог объявляет эти имена, обязан
нарисовать каждую форму целиком.

```ts
import { credit } from 'kit-fixtures';

const bundle = createForm({
  model: credit.createModel(),
  schema: credit.document,
  flow: credit.flow,
  registry,
});
```
