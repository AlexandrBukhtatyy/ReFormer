# MCP-сервер ReFormer для ассистента

Каталог `.ui_builder/mcp/<имя>/` — MCP-сервер проекта, который ассистент билдера запускает в Web
Worker и с которым говорит по MCP через `postMessage`. Имя сервера — имя каталога (`reformer`).

| Файл          | Что это                                                                                    |
| ------------- | ------------------------------------------------------------------------------------------ |
| `server.js`   | Бандл сервера: один самодостаточный скрипт воркера. В git не кладётся.                     |
| `server.json` | Необязательные настройки запуска. Здесь — `idleSeconds`: сколько воркер живёт без вызовов. |

## Откуда берётся `server.js`

В этом проекте-образце:

```bash
npm run mcp:build -w reformer-builder-playground
```

Скрипт собирает бандл из `packages/reformer-mcp` (нужен собранный пакет:
`npm run build -w @reformer/mcp`) и кладёт его сюда. В своём проекте достаточно скопировать готовый
бандл из пакета:

```bash
mkdir -p .ui_builder/mcp/reformer
cp node_modules/@reformer/mcp/dist/worker/server.js .ui_builder/mcp/reformer/
```

## Почему `idleSeconds: 600`

Воркер стартует по первому обращению и засыпает после простоя (по умолчанию — 5 минут). Корпус
знаний ReFormer — около 4 МБ JSON, и после каждого пробуждения он разбирается заново на первом
вызове. Поэтому этот сервер держится дольше умолчания: справку обычно спрашивают сериями.
