# ReFormer core — реализация бенчмарка

`@reformer/core` + headless `@reformer/cdk` на нейтральных примитивах (`src/shared/ui`). Порт демо
`projects/react-playground/src/pages/demo/registration-form` и `…/complex-multy-step-form`
(«React руками») с `@reformer/ui-kit` на общий UI; константы, формулы, сообщения и API — общие
(`src/shared/**`), а не демо.

## Паттерны и документация

Документация — `packages/reformer/docs/llms/*.md` (публикуется как llms-документация пакета),
`packages/reformer-cdk/docs/llms/*.md`.
